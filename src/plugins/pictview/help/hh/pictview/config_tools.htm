Select tool

Area selected when holding the Shift key
When you use the Select tool, holding down the Shift key selects a rectangle with a predefined aspect ratio. By default, the selected shape is a square. However, you can specify a different rectangle here as width : height. Several commonly used sizes for computer & TV screens and for photographs are predefined, and you can also choose any custom aspect ratio.

TIP: Only integers can be used for Other. To bypass this limitation, multiply your numbers by 10 or 100. For example, if you need the very specific ratio 1:1.234, specify 1000:1234 instead.

Other options

Pipette picks colors in hexadecimal
See Pick Color mode in Using Mouse in Viewer. When checked, the pipette tool shows colors as hexadecimal numbers (useful, for example, when editing HTML pages).
