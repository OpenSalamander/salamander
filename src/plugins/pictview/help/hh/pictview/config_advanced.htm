Open Salamander: Plugins: PictView: Dialog Boxes: Configuration

Advanced

Allows you to change advanced options in the viewer and thumbnailer.

Options

Ignore original thumbnails stored in image files (slower)
When checked, all thumbnails are generated from full-size images (slower, but more accurate). This is useful if your images contain incorrect or low-quality thumbnails and you do not want to update these thumbnails.
Do not create thumbnails of images with more than ??? megapixels
Here you can specify the maximum image size (the default is 90 megapixels, or 90 million pixels) for which PictView should prepare a thumbnail. This is only an optimization; preparing a thumbnail for an image that is too large may take too much time or tie up your computer for a while.
Autorotate EXIF JPEG images (digital camera pictures)
Modern digital cameras store in the JPEG image file whether the image was taken in portrait orientation or even upside down. When checked, PictView reads this information and automatically rotates the image to the correct orientation for display. This may take some time for larger images on slower computers.
Show message box on successful file save
When checked, you will be informed about every successful save of an image by a message box. When unchecked, only a short notification will be displayed in the status bar until the mouse is moved.
Remember path when saving screenshots, scans, clipboard pastes
This checkbox controls which folder is offered by default when saving a screen capture, scanned document, or an image pasted from the clipboard. When checked, the folder used for the last image of these types is offered. When unchecked, the current path of the active panel in Salamander is offered, or the last path if an archive or file system plugin (such as FTP) is currently open in the active panel.
