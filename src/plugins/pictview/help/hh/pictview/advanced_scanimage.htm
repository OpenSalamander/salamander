Scanning Image

You can scan documents directly into the viewer.

32-bit (x86) version:

If you have more than one scanner attached to your computer, use the Select Scanner Source command to choose the appropriate scanner. The 32-bit (x86) version uses the TWAIN interface for scanners. TWAIN x86 also provides the WIA interface (Windows Image Acquisition), so you should be able to use almost any scanner easily.

64-bit (x64) version:

If you have more than one scanner attached to your computer, you can choose the appropriate scanner whenever you start scanning. The 64-bit (x64) version uses the WIA interface (Windows Image Acquisition). TWAIN x64 is not directly supported by Windows and is supported by only some scanner manufacturers. If you cannot connect to your scanner from the 64-bit (x64) version, try connecting from the 32-bit (x86) version; it will probably work with your scanner.

To scan image:

  1. Start scanning an image:
    Menu:Plugins/PictView/Scan Image...
    Viewer menu:File/Scan Image...
    Viewer shortcut key:W
  2. The scanned image is displayed in a PictView viewer window. You can use the Save As command on the File menu to save this picture to a file.
