Capturing Screen

This command lets you capture the screen (take a screenshot). The resulting image is opened in the viewer so that you can easily save it to disk.

You can choose what to capture (entire screen, foreground window, etc.), the shortcut key or timer for capturing, and whether the mouse cursor should also be captured.

For simple screenshots copied to the clipboard, you can also use Windows shortcut keys. The first is the Print Screen (or PrtScn) key, which copies the entire screen to the clipboard. The second is the Alt+Print Screen (or Alt+PrtScn) key, which copies only the active window to the clipboard. You can then use the View Bitmap from Clipboard command to open the image in the PictView viewer.

To capture the screen:

  1. Open the Screen Capture dialog box:
    Menu:Plugins/PictView/Screen Capture...
    Viewer menu:File/Screen Capture...
    Viewer shortcut key:Q
  2. Select what you want to capture.
  3. Set the keyboard shortcut or timer for the capture.
  4. Choose whether to include the mouse cursor.
  5. Click the Capture button.
  6. Arrange your windows and mouse pointer before capturing.
  7. Use the selected keyboard shortcut or wait for the timer.
  8. The captured result is displayed in a PictView viewer window: it is shown in the same window if the capture was invoked from an existing PictView window, or in a new PictView window if it was invoked from the Plugins menu. You can use the Save As command on the File menu to save this picture to disk.
