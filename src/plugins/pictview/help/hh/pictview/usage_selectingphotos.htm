Selecting Photos

If you decide to have your photos printed at a photo lab, you will need to select the right image files (photos) and burn them to a CD or upload them directly to the photo lab. Here are some tips for selecting image files in the directory more easily:

  • Use the View command from the panel to open the first photo in the viewer.
  • Maximize the viewer window to better see your photos.
  • Use the Space key to view the next photo or the Backspace key to view the previous photo. If you want to view the next or previous selected photo, use the Ctrl+Space or Ctrl+Backspace keys. See more in Opening Previous or Next File from the Panel or Find Window.
  • Use the Insert key in the viewer to select the current image file in the panel if it is not already selected, or to clear the selection if it is. You can see whether the photo is selected on the toolbar button Select/Unselect Opened File in the Panel or Find Window. See more in Selecting File in the Panel or Find Window.
  • When you finish making your selections, close the viewer and work with the selected image files in the panel.
