Open Salamander: Plugins: PictView: Dialog Boxes: Configuration

Appearance

This tab lets you change the appearance of the PictView viewer. See Configuring Plugins for general information about configuration.

Options

Window size
Specifies the size of the viewer window when you open it. Select one of the following settings:
Option Meaning
Same as of Open Salamander The viewer window is the same size as the main window of Open Salamander.
Larger if needed but no smaller The viewer window is the same size as, or larger than, the main window of Open Salamander. It becomes larger if the image at 100% zoom (1:1) needs a larger window.
As needed The viewer window is the smallest size that can display the image at 100% zoom (1:1).
Default zoom
Specifies the zoom used in the viewer window when you open it. Select one of the following settings:
Option Meaning
Fit whole (no scrollbars) Calculates the zoom percentage needed to show the whole image in the viewer window.
Fit to width (no horizontal scrollbar) Calculates the zoom percentage needed to show the entire width of the image in the viewer window (this avoids horizontal scrolling, but vertical scrolling may still be needed).
Original size Uses 100% zoom (one pixel of the image is one pixel in the viewer window).
Full screen Shows the image in full-screen mode. It calculates the zoom percentage needed to show the whole image in the full-screen view.
Show image file path in titlebar
When checked, the viewer title bar contains the full path to the image file. Otherwise, it contains only the image filename (without the full path).
