Using Mouse in Viewer

You can choose one of four mouse modes for the left mouse button in the viewer; see the following table. Click the right mouse button to display the context menu with the most important commands. Double-click the left mouse button to view the image in full screen or to exit full-screen view. The mouse wheel can be used to scroll the image up and down or to open the next or previous image file from the panel or from the Find window's found files list; see Keyboard & Mouse tab in Configuration and Opening Previous or Next File from the Panel or Find Window.

Left mouse button modes:

ModeShortcut key
HandA
ZoomZ
SelectS
Pick ColorP

You can find all these mouse modes in the viewer's Tools menu.

Hand

This mode is useful if you cannot see the whole image in the current view (the image at the current zoom level is larger than the viewer window). Press and hold the left mouse button to grab the image, then move the mouse to scroll it in the desired direction. To stop scrolling, release the left mouse button.

Zoom

Use this mode to change the zoom. Click the left mouse button to zoom in to the next preset percentage and center the view around the point you clicked. Press and hold the Shift key, then click the left mouse button to zoom out to the previous preset percentage.

You can also use marquee zoom. Select the area of the image that you want to fill the view. To start, press and hold the left mouse button. This defines the first corner of the area (the opposite corner is dragged by the mouse pointer). When you press and hold the Space key, you move the whole area, not just the second corner. While dragging, you can move the mouse pointer near the edge of the view to scroll it.

Select

You can define a selected area of the image in this mode. The selection is used by several commands, including Crop, Copy, and Print.

To define the selected area, press and hold the left mouse button. This defines the first corner of the area (the opposite corner is dragged by the mouse pointer). When you press and hold the Space key, you move the whole area, not just the second corner. Press and hold the Shift key to constrain the area to a square. While dragging, you can move the mouse pointer near the edge of the view to scroll it.

See also: select the whole image or cancel the selection.

Pick Color

Use this mode to see the coordinates (relative to the top-left image corner) and RGB values of the image pixel under the mouse pointer.
