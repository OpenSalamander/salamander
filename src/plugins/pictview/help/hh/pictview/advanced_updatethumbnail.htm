Updating Thumbnail

Most digital cameras store thumbnails (small previews of the image — the usual size is 160 x 120 pixels, with a file size of about 10 KB) directly in JPEG files. They make image file thumbnails display very quickly (see Selecting Current View in the panel) because it is not necessary to read the entire images and scale them down to thumbnails.

Unfortunately, some image editors do not update thumbnails stored in images. When you change an image in such editors (for example, by rotating or cropping it), they may simply copy the original unchanged thumbnail (so you see an out-of-date thumbnail) or ignore thumbnails entirely (which makes thumbnail retrieval slower). In both cases, you can use PictView to update the thumbnail stored in the image file.

To update a thumbnail inside a JPEG file:

  1. Select one or more files in which you want to update the thumbnails.
  2. Start updating the thumbnails:
    Menu:Plugins/PictView/Update Thumbnail
