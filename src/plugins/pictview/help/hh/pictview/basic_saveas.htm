Saving Image

You can save the image opened in the viewer to disk in one of many supported file formats, with the desired compression type and additional format-specific options (JPEG quality, color depth, mirroring, GIF interlacing, TIFF stripping, etc.).

To save image:

  1. Open Save As dialog box:
    Viewer menu:File/Save As...
    Viewer shortcut key:Ctrl+S
  2. Enter new filename.
  3. Select image file type.
  4. Choose compression and additional file type options (quality, color depth, etc.). To show them, click the Options button.
  5. Click the Save button.

Tips and tricks:

  1. If you do not want PictView to append the default file extension, enter your extension and add an extra dot after it. Example:
    • MyImage.jpeg.
  2. PictView avoids creating awkward filename casing. If the resulting base filename is in uppercase and the default extension is in lowercase, PictView converts the filename to lowercase as well. Entirely uppercase filenames usually originate from FAT, NWFS, or ISO 9660 file systems; they are created by legacy 16-bit applications or transferred via FTP, SFTP, or FTPS from other systems.
    If you really want the entire filename to remain in uppercase, or you want a mixed-case base filename with a lowercase extension, enter the entire filename, including the extension, using the desired case. Examples:
    • MYIMAGE.JPG
    • MYIMAGE.jpg
