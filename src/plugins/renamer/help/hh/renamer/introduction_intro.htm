Getting Started with Renamer Plugin

With the Renamer plugin, you can rename many files and directories (optionally including subdirectories) in a batch using specified rules. For example, you can search for substrings in names and replace them; insert size, time, and date stamps; insert counters with decimal or hexadecimal base; use regular expressions for sophisticated substitutions and reordering; change the case of names and extensions; rename filenames including full or relative paths (moving files to other directories); and use manual mode for direct filename renaming (like in a text editor). All planned changes are shown in a real-time preview of the resulting names. These changes are committed to disk when you click the Rename button. If needed, you can revert all rename operations performed using the Undo command.
