Open Salamander: Plugins: Renamer: Introduction

Getting Started with Renamer Plugin

With the Renamer plugin you can rename many files and directories (optionally including subdirectories) in a batch using the specified rules. You can e.g. search for substrings in names and replace them with something else; insert size, time, and date stamps; insert counters with decimal or hexadecimal base; use regular expressions for sophisticated substitutions and reordering; change the case of names and extensions; rename also filenames including full or relative path (move files to other directories); and use manual mode for direct filenames renaming (like in a text editor). All planned changes are visible in a real-time preview of resulting names. These changes are committed to disk when you click the Rename button. Moreover, in case of need, you can revert all performed rename operations using the Undo command.
