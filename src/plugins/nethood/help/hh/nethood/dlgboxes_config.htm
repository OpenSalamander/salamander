Open Salamander: Plugins: Network: Dialog Boxes

Network Configuration

You can customize the Network plugin in this dialog box. See Configuring Plugins for general information about configuration.

Options

Show administrative shares
When checked, the plugin will also display special administrative shares (ADMIN$, C$, D$, and so forth) in the panel.
Show administrative shares as hidden items
When this option is checked together with Show administrative shares, the plugin marks special administrative shares (ADMIN$, C$, D$, and so forth) with the hidden attribute. To show these shares, clear the Hide files and directories with hidden or system attribute check box (see Panels tab in Salamander's Configuration).
Show items from My Network Places at top level directory
When checked, items from the My Network Places folder are listed in the Network plugin root directory. Turn this option on to match Windows 2000/XP behavior.
Show network computers at top level directory
When checked, computers from the current workgroup or domain are listed in the Network plugin root directory.
Show disks connected via Remote Desktop
If enabled, disks connected through the Remote Desktop Protocol or by using Windows XP Mode (available in Windows 7) are accessible from the Local Computer or Host Computer folder.
Scan network on start of Salamander
When checked, the plugin scans the network in the background when Salamander starts. When you activate the plugin for the first time, you immediately see all computers that were available when Salamander started, and this list is refreshed in a few seconds to reflect the current state of the network.
