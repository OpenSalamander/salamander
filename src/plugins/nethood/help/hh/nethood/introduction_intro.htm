Open Salamander: Plugins: Network: Introduction

Getting Started with Network Plugin

With the Network plugin, you can browse the network directly in a panel. It displays a list of available computers on the network and their shares.

This plugin is convenient for browsing the network because it is non-blocking (the panel is not blocked while information is being read from the network) and cached (all visited computers and their shares are remembered).

See the File System section in Using Plugins for a description of basic work with file system plugins.
