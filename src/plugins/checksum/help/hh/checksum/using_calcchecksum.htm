Calculating Checksums

Use this dialog to calculate CRC32, MD5, SHA-1, SHA-256, and SHA-512 checksums of files. You can save these checksums to a file for later verification of file integrity.

To calculate checksums:

  1. Select the files and directories (all files in selected directories are included) for which you want to calculate CRC32, MD5, SHA-1, SHA-256, or SHA-512 checksums.
  2. Open the Calculate Checksums dialog box:
    Menu:Plugins/Checksum/Calculate Checksums...
  3. Note that this dialog is not modal (not blocking), so you can continue working in Altap Salamander while checksums are being calculated.
  4. When checksums are ready, you can see them in the CRC, MD5, SHA-1, SHA-256, and SHA-512 columns.
    NOTE: Not all columns may be visible (not all checksum types may be calculated), depending on the Configuration.
  5. To copy a specific file's checksum to the clipboard, right-click the filename.
  6. Use the Save button to save the checksums to a file for later checksum verification. Select the desired format in the Save Checksum File dialog box that appears.
  7. Click the Close button to close the dialog box.
