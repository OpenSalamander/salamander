Frequently Asked Questions

Can I customize the Self-Extractor dialog box?
Yes, the ZIP Plugin and Zip2Sfx provide options for customizing the dialog box. You can set the dialog box title, the text displayed in the dialog box, and the text of the button that starts extraction. You can also add a custom icon to the dialog box. See the Self-Extractor Texts dialog for details.

Is it possible to change the Extract to directory when running a self-extracting archive, even if the archive was created with an option that disables changing the Extract to folder or with an option that causes automatic extraction?
Yes. Users can run the self-extracting archive with the command-line option -s to start the self-extracting archive in safe mode. See Self-Extractor Command Line Parameters for details.

What is an sfx package?
An sfx package is a file with the extension .sfx. It contains the Self-Extractor executable and language-dependent data such as the text in the main dialog. Data from the sfx package is used when creating a self-extracting archive.

Where are sfx packages stored?
Sfx packages are stored in the plugins\zip\sfx subdirectory of Open Salamander's installation directory.
