Open Salamander: Plugins: ZIP: Using ZIP Plugin

Create New Archive Dialog

This dialog is displayed just before packing to a ZIP archive starts (using the Pack or Copy command). This dialog is labeled Add Files to Archive when adding files to an existing archive (i.e., using the Copy command). You can specify packing options here. Packing starts immediately with the default settings if the display of this dialog is disabled in the ZIP plugin configuration.

Dialog Box Options

Create multi-volume archive
Allows you to create a multi-volume (spanned) archive. The archive file is split into several files (volumes) with a specified maximum size. Typical use: storing files on removable media (floppy disks, CD-ROMs, etc.). The ZIP plugin also allows you to create multi-volume archives stored on fixed disks (with sequential filenames; see below).
Volume size
Maximum size of each archive volume. If you select automatic, the ZIP plugin will detect the free space on each inserted medium at the target path and set the maximum volume size accordingly.
Name files sequentially
Allows you to add a volume number to each archive volume. If you are packing to a fixed drive, this option is necessary because it is impossible to store multiple files with the same name in the same directory.
Note: Not all zip archivers support multi-volume ZIP archives stored on fixed disks or archives with sequential naming.
Create self-extracting archive
Enables you to create an archive that can extract itself. For more details, see Self-Extracting Archives.
Advanced
Displays Self-Extractor Settings dialog.
Encrypt files
Enables file encryption. This option does not affect files that are already in the archive.
Encryption Method
The ZIP plugin supports two different encryption schemes. The legacy ZIP 2.0 method is now considered weak (experts say they need less than two hours on a Pentium 500MHz with 128MB RAM, and the security is not dependent on the password length). The second supported scheme is the modern Advanced Encryption Standard (AES), with two key lengths: 128 bits and 256 bits. The longer key provides better security at the expense of slightly longer encryption and decryption times. The key is generated from the user-provided password using the algorithm described in the RFC2898 document.
Warning: While virtually any software capable of handling ZIP archives can extract files encrypted with the legacy method, not all software can handle AES-encrypted archives.
Warning: To achieve good security, it is highly recommended to use long passwords (more than 30 characters) mixing digits, lower-case and upper-case characters, and other non-alphabetical symbols, such as colons.
You may also use the Encrypt plugin if you need a higher level of security for your files.
Don't show this dialog again
Suppresses display of this dialog before each packing to a ZIP archive. You can enable display again in the ZIP Configuration.
Configure
Opens the ZIP Configuration dialog.
