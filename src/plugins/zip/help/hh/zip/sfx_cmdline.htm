Self-Extractor Command Line Parameters

The user can start the self-extracting archive with the command-line option -s. With this option, the self-extracting archive starts in safe mode. This means that the following self-extractor options are enforced: Allow user to change the directory is checked, Start extraction automatically is cleared, and Hide main self-extractor's dialog is cleared. As a result, it displays the main self-extractor dialog box and allows the user to specify the Extract to directory.
