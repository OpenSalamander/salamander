Menu Commands

The Self-Extractor Settings dialog contains the following menu commands:

In File Submenu:

Export Settings
Saves the current self-extractor settings to a settings file in a human-readable and editable text format.
Import Settings
Loads self-extractor settings from a settings file. See sample.set for a sample of self-extractor settings. It also contains details about the syntax of self-extractor settings.

In View Submenu:

Preview
Displays a preview of the self-extractor's main dialog box.

In Options Submenu:


Reset All
Restores both the default values in the Self-Extractor Settings dialog and the default texts entered in the Self-Extractor Texts dialog.
Reset Values
Restores only the default values in the Self-Extractor Settings dialog (it does not affect the texts entered in the Self-Extractor Texts dialog).
Reset Text
Restores only the default texts entered in the Self-Extractor Texts dialog (according to the selected language; it does not affect the values in the Self-Extractor Settings dialog).
Add to Favorites
Saves the current settings (including texts) to the Favorites submenu (see its description below).
Favorites
Contains all saved settings (including texts). To load these settings, just click the appropriate menu item. To manage these settings, click the Manage item in this menu.
Last Used
Loads the last used self-extractor settings (including texts).
