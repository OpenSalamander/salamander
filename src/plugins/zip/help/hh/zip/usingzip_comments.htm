Open Salamander: Plugins: ZIP: Using ZIP Plugin

Archive Comment

A ZIP archive can contain two types of comments: comments for individual compressed files, and a comment for the entire archive. The ZIP plugin allows you to view, add, and edit only the archive comment.

To view or edit the archive comment:

  1. Select the ZIP archive file for which you want to view or edit the comment.
  2. Choose the Archive Comment command from the menu Plugins/ZIP.
