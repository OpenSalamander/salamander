Open Salamander: Plugins: ZIP: Using ZIP Plugin

ZIP Configuration

Here you can set general options for the ZIP plugin. You can access configuration either from the Open Salamander Plugins Manager dialog (menu Plugins/Plugins Manager), or from the Create New Archive dialog. See Configuring Plugins for general information on configuration.

Options

Automatically expand multi-volume archives stored on fixed disk
Automatically finds the last archive volume file (which contains information about the files in the archive) without prompting the user to locate it. When the last volume is found, it lists or unpacks files without prompting for other archive volumes. This option applies only to multi-volume archives stored on fixed disks, not to archives on removable media (e.g., floppy disks, CD-ROMs).
Use temporary copy of archive for its modifications
For any action that changes a ZIP archive (such as packing or deleting files), the ZIP plugin first creates a backup copy of the archive and performs the desired action on the backup copy. When the action completes successfully, the original archive is replaced by the updated archive. In case of an error, the original is left unchanged. This approach causes a slight slowdown due to the backup operation, but it is strongly recommended to have the ZIP plugin create backup copies while modifying archives.
Don't store empty directories in ZIP archive
Ignores empty directories when packing. This option does not affect empty directories that are already stored in the archive.
Set archive time to the newest file time when modifying archive
After any action that modifies an archive (packing or deleting files), the ZIP plugin sets the archive file time to the time of the newest file in the archive. This option can be useful for tasks such as backup management.
Use WinZip compatible file names for multi-volume archives
Multi-volume archive parts are named using WinZip naming conventions, except for self-extracting archives, which use Open Salamander naming conventions.
Compression level
Specifies how much the files should be compressed. Level 0 means store - no compression. Level 9 is the best possible (and slowest) compression that can be achieved with the current ZIP compression algorithm (deflate).
Default self-extractor language
The default language for self-extracting archives. If you opened the ZIP Configuration dialog from the Create New Archive dialog, changing the default language will not affect the current pack operation (use the Advanced button from the Create New Archive dialog to change the language for the current pack operation).
When SFX language changes
You can specify your own texts for the main window of the self-extracting archive and an optional message box that is displayed before the main window (see Self-Extractor Texts dialog). Choose what should happen when you are using such custom texts and change the language of a self-extracting archive. Options are: Always ask before changing texts, Automatically replace texts with their default values, or Don't ask and leave always texts unchanged.
Display dialog with extended options before packing
Displays the Create New Archive/Add File to Archive dialog before each pack operation to ZIP archives. This lets you specify many packing options offered by the ZIP plugin (such as archive spanning, self-extracting archives, or encryption).
Show column Packed when listing archive
Controls whether an extra column Packed showing the compressed size of each file should be added to the panel listing the archive in Detailed mode or Types mode.
