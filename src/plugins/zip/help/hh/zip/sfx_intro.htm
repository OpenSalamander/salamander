Open Salamander: Plugins: ZIP: Self-Extracting Archives

Introduction

A self-extracting archive is an executable file (.exe) that contains a ZIP archive and the Self-Extractor (software that unpacks/extracts the archive). In the ZIP plugin, you can create self-extracting archives with many useful options.

The main advantage is that anyone can extract files from a self-extracting archive without needing any other software (a ZIP unpacker) or knowing how to use a separate unzip utility. Thus, self-extracting archives are particularly well suited for distributing software to beginning users who are not familiar with the concept of ZIP archives. You can also use them when transporting a ZIP archive to a computer where the required ZIP software may not be installed.

Using the Self-Extractor, you can compress your installation software. After the installer is extracted, the Self-Extractor starts the installation or executes any other command you have specified. When the installation finishes, the Self-Extractor removes all temporary files.
