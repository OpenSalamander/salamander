Mouse Shortcuts

There are many mouse shortcuts defined in File Comparator.

You can:
  • Select text by dragging the mouse pointer over it
  • Select one word by double-clicking on it with the left mouse button
  • Select full lines by dragging the mouse pointer over text while holding down the Ctrl key
  • Select one line by double-clicking in it with the left mouse button while holding down the Ctrl key
  • Focus a difference by clicking on it with the left mouse button
  • Focus and select an entire difference by double-clicking on it in the line numbers column with the left mouse button
  • Display the context menu by right-clicking in the text window
