Getting Started with Quake PAK Plugin

The Quake PAK plugin adds support for packing, browsing, and unpacking id Software PAK files from Quake, Quake II, and their modifications.

Note: PK3 files that came with Quake 3 Arena are actually ZIP files and are therefore handled by the ZIP plugin.

See the Archiver section in Using Plugins for a description of basic work with plugin archivers.
