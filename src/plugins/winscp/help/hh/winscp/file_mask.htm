Open Salamander: Plugins: WinSCP: Appendix

Masks

To use the following WinSCP features, you need to specify a mask (wildcard) to select files (or other things):

  • Text file mask for text mode transfers.
  • Ignore mask for transfers.

Filename Mask

When specifying the mask, you can use the following patterns:

Pattern Meaning Example
* Matches any number (including zero) of arbitrary characters. *.doc; about*.html
? Matches exactly one arbitrary character. photo????.jpg
[abc] Matches one character from the set. index_[abc].html
[a-z] Matches one character from the range. index_[a-z].html

All other characters are treated literally.

To escape a character with special meaning (*?[), enclose it in a set pattern, e.g., filewithstar[*].

Directory Mask

When specifying an include mask for transfers, keep in mind that it is also applied to directories, so *.bak will only match backup files located in the current directory (unless you have a subdirectory whose name ends in ".bak", in which case it will also be applied to all backup files in that subdirectory).

A mask ending with a slash matches only directories. The mask */ matches any directory.

For example, to transfer only HTML files located in any directory, use the include mask */; *.html (see below for information about combining masks).

To make an operation non-recursive, use the exclude mask */.

Path Mask

When a mask selects files and it makes sense to select them by directory, you can extend it with a path mask. You should separate the path mask from the filename mask with a slash. For example, the mask /home/martinp/*.txt matches all text files within the directory, but not in subdirectories. To match all text files within the subtree, use the mask /home/martinp/*.txt; /home/martinp/*/*.txt (a simpler but less precise form would be /home/martinp*/*.txt).

For a relative path mask, it makes no difference whether you use backslashes (\) or forward slashes (/); the mask will always work for both local and remote paths. For example, the mask */public_html/*.bak will match backup files both in D:\Documents\public_html and /home/martinp/public_html. If you want to match only directories, add a slash at the end of the mask.

You can also specify the full path to a specific local or remote file or directory. For example, if you want to match only a specific .csv directory and not all of them, use /home/martinp/data/.csv/ instead of .csv/.

When specifying an include mask for transfers, keep in mind that it is also applied to directories, so *.bak will only match backup files located in the current directory (unless you have a subdirectory whose name ends in ".bak", in which case it will also be applied to all backup files in that subdirectory).

The mask */ matches any directory. For example, to transfer only HTML files located in any directory, use the include mask */; *.html.

Exceptions

For convenience, the masks *.* and *. are exceptions that match any file and any file without an extension, respectively, even if the filename does not include any dot.

Combining masks and exclude mask

You can combine several masks using a semicolon (;) or comma (,).

You can add an exclude mask by separating it with a pipe (|) from the include mask. To use an exclude mask only, start with a pipe immediately.
