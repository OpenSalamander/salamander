Open Salamander: Plugins: WinSCP: Features

Background Transfers

By default, WinSCP transfers files in the foreground. This way it can use one connection to the server all the time; however, during the transfer you cannot use Open Salamander for any other task. An alternative way is to use background transfers.

Transferring Files in the Background

To instruct WinSCP to perform the transfer in the background, check Transfer on background in the Transfer Options Dialog before the transfer. If you do not use the dialog or want to transfer files in the background by default, check Transfer on background by default on the Background & Resume tab of the Preferences dialog.

Once you instruct WinSCP to perform the transfer in the background, a separate transfer progress window is shown. WinSCP opens a separate SSH connection to the server using the same session options as used for the main session. Once the transfer finishes, the connection is kept in the background and reused for future transfers.

Once the background transfer finishes, the target directory is reloaded (still in the background), and the content of the respective file panel is refreshed.
