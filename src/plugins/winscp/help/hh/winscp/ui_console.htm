Console Window

The Console window appears to display the output of remote commands.

After reviewing the output of the executed command, you can close the window or execute another command.

Read more about limitations of the console.

Note that if the output does not fit into the window, you can scroll the output, resize the window, or use the command Adjust Window from the context menu.
