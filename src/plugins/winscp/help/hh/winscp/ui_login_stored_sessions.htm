Stored Sessions Tab (Login Dialog)

The Stored Sessions tab allows you to manage stored sessions. It also lets you set default session options.

The list box shows a list of already saved stored sessions. You should select a session to work with before pressing one of the Login, Edit, Delete, and Rename buttons. Double-clicking a session has the same effect as selecting it and pressing the Login button, as long as at least the host name and username are filled.

The sessions can be organized into folders. Expand/collapse a folder by double-clicking on its name.

The New button resets session options on the Login dialog to the default ones and switches to Session tab.

The Edit button loads options for the selected stored session to the Login dialog and switches to the Session tab to allow modifications. To edit an existing stored session, first load it, modify your options, and then save it back (under the same or a different name).

The Delete button deletes the selected stored session or session folder. Deleting a session folder deletes all the sessions it contains.

Use the Rename button to rename the selected stored session or session folder.

Use the New folder button to create a new session folder. To create a subfolder, use path syntax "folder/subfolder" (Select the parent folder before pressing the button to have the path prefilled). Note that empty folders are not preserved.

The Set defaults button sets the current session (not the selected stored session) options as defaults. This means that they will be used when WinSCP starts the next time and whenever the New button is pressed.
