Synchronization Checklist

You will be presented with the synchronization checklist if you have enabled the Preview changes option on the Synchronize dialog. In the checklist, you can select the synchronization actions you want to apply.

Information Displayed

In the checklist, there is one row for each synchronization action. For each action, you can see the action type, visualized by an icon. Green arrows indicate a new file that does not exist in the target/destination directory and will be copied to the directory that the arrow points to (see note 1). Blue arrows indicate a changed file that will be copied to the directory (overwriting the file with the same name) that the arrow points to (see note 1). And finally red crosses indicate a file that only exists in the target/destination directory and will be deleted (see note 1). For each action, you can also see the name of the file or directory (directories end with a slash and can be distinguished also by an icon), and their attributes in either the local or remote directory, or both (for updated files). The Local/Remote directory columns indicate the location of the files/directories relative to the root directory of synchronization.

Selecting Actions

To select actions to be applied, use the check box at the very beginning of each row. To check more actions at a time, select them and use the buttons (Un)Check or the context menu. Note that you can select all actions or a certain type (like local file updates) by clicking on the respective section of Status bar (at the bottom of the window). To add the actions to the existing selection, hold down the Ctrl key while clicking.

Note that initially, only those actions that you have requested by your synchronization options will be checked. That is, if you have not enabled the option Delete files, the deletion actions will be unchecked.

Notes:

1) If the box on the left is checked.
