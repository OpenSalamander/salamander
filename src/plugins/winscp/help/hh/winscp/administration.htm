Open Salamander: Plugins: WinSCP: Appendix

Administration Tasks

WinSCP allows system administrators to restrict or enforce certain functionality of the application.

Configuring the Restrictions

System administrators can configure the following:

  • Restrict password storing.
  • Restrict connection to servers without having their host keys accepted in advance.
  • Force authentication banners to be shown.

These restrictions are configured via the "local machine" registry root key (modifiable only by system administrators). An example of the corresponding registry export follows:

REGEDIT4

[HKEY_LOCAL_MACHINE\SOFTWARE\Martin Prikryl\WinSCP 2]
"DisablePasswordStoring"=dword:00000001
"DisableAcceptingHostKeys"=dword:00000001
"ForceBanners"=dword:00000001

Unmodifiable Stored Session

Administrators can set the session setting Special to 1 to prevent users from modifying or deleting the session accidentally (note that the setting can be changed by the end user). Such sessions will also be highlighted in the session list.
