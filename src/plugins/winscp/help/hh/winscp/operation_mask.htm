Operation Mask

When using some features of WinSCP, you can specify an operation mask. For example, in:

  • Target directory/file box in the Transfer Options Dialog when uploading or downloading files.
  • Target directory/file box when moving or duplicating remote files to a different remote directory.

An operation mask can be used to change the name of the file being transferred or moved.

The simplest operation mask is a new filename. For example, when you are uploading a file and you type /home/martinp/configuration.txt in the target directory/file box, the file will be stored in the remote directory /home/martinp under the name configuration.txt, regardless of the original filename.

Such a simple operation mask is useful only when transferring or moving a single file. When you are working with a set of files, you need to use some of the special characters to allow each file to be stored under a different, yet modified, name. In addition, the mask can have two parts separated by a dot (.), which allows you to change the base filename and the filename extension separately. These special characters are:

Character Meaning Example
* Keep all remaining characters of a part of the source filename as is. a*.doc to change the first letter of all files to a and to change the extensions of all files to doc.
? Keep the next character of a part of the source filename as is. *.??~ to replace the third letter of the file extension with ~.
\ Treat the next character literally (only for changing names of remote files, i.e., for upload). \* to store file under the name *.

All other characters are treated literally, i.e., they will become part of the target filename.

By default, WinSCP offers the operation mask *.*, which leaves the filename as is. Note that you will achieve the same effect with simply * (but not with *., which would trim the file extension).
