Open Salamander: Plugins: WinSCP: Dialog Boxes: Configuring Session

Directories Tab (Login Dialog)

The Directories tab allows the user to configure the initial session directory and the way directory content is read.

Directories

When the Remember last used directory checkbox is ticked, the initial directory for the session (see Remote directory) is always updated with the last opened directory from the previous session. The option makes sense only if you save your session preferences to a stored session, because it is the stored session that is updated when each session closes.

The Remote directory box defines the initial remote directory opened in the panel. When Remember last used directory is ticked, the path is updated whenever the session is closed. When the initial directory is not specified, the user home directory is usually opened on startup. Note that this may not be true, particularly for SFTP servers.

Directory Reading Options

The section is hidden, unless advanced options are enabled.

Cache visited remote directories, Cache directory changes and Permanent cache checkboxes control directory cache.

When WinSCP reads directory content, it by default also resolves any symbolic links (symlinks) it finds, particularly to learn whether they point to a file or directory. If a directory contains too many symbolic links, it can slow down opening the directory. You may disable the feature by unticking Resolve symbolic links to speed it up. You may also use the option when WinSCP hangs when resolving cyclic links. While WinSCP detects most cyclic links, it can still hang when it encounters more complex symbolic link "systems". When the resolving is disabled, double-clicking on any remote file will be interpreted as an attempt to open the directory with the same name. This allows opening links pointing to directories even when WinSCP does not know they are links.
