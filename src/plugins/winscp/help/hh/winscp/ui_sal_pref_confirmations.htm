Confirmations Tab (Preferences Dialog)

The Confirmations tab lets you enable or disable several confirmation boxes that can appear during various tasks. Some of these confirmations can also be disabled using the Never ask me again checkbox on the respective message box (you need to answer it positively to confirm the preference).

The Always keep connection, when leaving SFTP/SCP panel checkbox disables the disconnect confirmation shown when the WinSCP panel is being replaced with another panel.

The Overwriting of files checkbox enables overwrite confirmation during file transfers. You also need to have it enabled if you need to use alternative method of transfer resuming.

The Transfer resuming checkbox enables confirmation of transfer resume. When disabled, the transfer is resumed automatically whenever possible (excluding alternative method of transfer resuming).

The Exiting application on operation completion checkbox enables an information message shown before the application is closed after an operation (like file transfer) is finished. That is, when some finalizing operation was selected. When unchecked, the application closes immediately.

The Opening separate shell session checkbox controls whether opening separate shell session requires confirmation.

The Display dialog box with options before uploading checkbox enables Transfer settings dialog before upload. Disable it, if you do not want to confirm two boxes before each upload.
