Saving Session Configuration

If you want to save your session configuration, use the Save button at the bottom of the Login dialog to create a stored session. You will be asked for the name of the stored session. From the drop-down menu, you can select the name of any existing stored session to overwrite it.

To store a session in a folder, use path syntax "folder/session" (Select the folder on Stored sessions tab in advance to have the path prefilled).

If you have specified a password on the Login dialog, you will have an option to save it as well using the Save password checkbox. However, this is not recommended unless you protect it with a master password. Read more about security when storing passwords.

System administrators can create stored sessions that cannot be modified or deleted.
