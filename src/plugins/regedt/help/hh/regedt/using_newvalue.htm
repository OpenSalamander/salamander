Open Salamander: Plugins: Registry Editor: Using Registry Editor Plugin

Creating New Value

When you need to create a new value in a specified key in the Windows registry, use this command.

To create a new value in the registry:

  1. In the panel, open the key where you want to create a new value.
  2. Open the New Value dialog box:
    Menu:Plugins/Registry Editor/New Value...
    Context menu:Open the context menu in the panel (right-click or Shift+Alt+F10) and choose New Value...
  3. Enter the value name and type.
  4. Choose the OK button.
