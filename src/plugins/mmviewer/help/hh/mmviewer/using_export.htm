Exporting Information to an HTML File

You can export information from multimedia files to an HTML file using this command.

To export information from multimedia files to an HTML file:

  1. Select the multimedia files whose information you want to export.
  2. Choose the Export Info into HTML... command:
    Menu:Plugins/Multimedia Viewer/Export Info into HTML...
  3. Specify the name of the exported HTML file.
  4. Choose the Save button.
