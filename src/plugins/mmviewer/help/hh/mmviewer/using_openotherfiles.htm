Opening Previous or Next File from Panel or Find Window

When you have multiple multimedia files in a directory shown in a panel or in the found files list of the Find window, you can use the View command on the first of them and then view all the others in the same viewer window one by one using the following commands:

  • Previous (the Backspace key): open the previous multimedia file,
  • Next (the Space key): open the next multimedia file,
  • First (the Shift+Backspace key): open the first multimedia file,
  • Last (the Shift+Space key): open the last multimedia file.

Note: these commands work only until you change the content of the panel or Find window from which you opened the viewer.

You can find all these commands in the viewer submenu: File/Other Files.
