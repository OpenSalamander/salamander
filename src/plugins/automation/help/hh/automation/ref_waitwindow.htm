WaitWindow Object

The WaitWindow object represents the wait window. Wait windows are used to inform users about lengthy operations whose progress cannot be determined. The ProgressDialog object is a better choice when the progress of a lengthy operation can be reported.

Methods

Name Description
Hide Hides the wait window.
Show Shows the wait window.

Properties

Name Description
CanCancel Determines whether the user can cancel the wait window.
Delay Gets or sets the initial delay before the wait window is displayed.
IsCancelled Determines whether the user has cancelled the wait window.
Text Gets or sets the text displayed inside the wait window.
Title Gets or sets the wait window title.
