GetFullPath Method

The GetFullPath method returns an absolute path for the specified path.

Syntax

GetFullPath(path, [panel])

Parameters

path

Required. Absolute or relative path to convert to a fully qualified absolute path.

panel

Optional. Specify this parameter when the path parameter is relative to the source or target panel. Set it to SourcePanel for the source (active) panel and TargetPanel for the target (inactive) panel. When this parameter is not specified or is null, the path parameter must be an absolute path.

Return Values

Returns the fully qualified absolute path.

Remarks

This method uses the current directories to resolve the absolute path, so the path can be specified in a form such as "c:test".

Redundant path parts such as "." and ".." will be resolved.

This method throws an exception if the specified path is invalid.
