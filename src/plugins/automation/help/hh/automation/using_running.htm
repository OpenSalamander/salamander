Running Your Scripts

There are two ways to run your scripts. You can either save your script in a script repository or run an arbitrary script.

Running Scripts from a Repository

The Automation plugin searches the script repositories for available scripts. These scripts are added to the Automation plugin menu and are available from the Plugins menu, from the Plugin Bar, or by using the Automation Open Script Menu command (Ctrl+Shift+A).

Script repositories are directories (including subdirectories) that can be set up in the configuration.

The default script repositories are: $[AppData]\Open Salamander\Automation\scripts, $[AllUsersProfile]\Open Salamander\Automation\scripts, $(SalDir)\plugins\automation\scripts. $(SalDir) is the full path of the Open Salamander directory; $[ENV_VAR] is the value of an environment variable (replace ENV_VAR with the environment variable name).

You can assign a shortcut key to frequently used scripts in the Plugin Keyboard Shortcuts dialog box.

Running an Arbitrary Script

To run an arbitrary script, focus the script file in a panel and select Run Focused Script from the Plugins or Script menu.

Aborting Script Execution

You can abort a running script at any time by using the Abort Script toolbar button or the Ctrl+Break keyboard shortcut.
