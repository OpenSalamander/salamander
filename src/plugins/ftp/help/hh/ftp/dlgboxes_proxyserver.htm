Open Salamander: Plugins: FTP Client: Dialog Boxes

Add/Edit Proxy Server

Use this dialog to specify new settings for a proxy server or change existing ones. A proxy server is an intermediary between the local network (intranet) and the Internet. Contact your network administrator if you are not sure how to specify these settings. This dialog can be opened by using the Add or Edit button in the Advanced Options dialog box or in Configuration/Defaults.

Options

Name
Choose some name (for future reference) for these settings for the proxy server.
Type
Choose the type of the proxy server.
Address
Specify the address (usually IP address) of the proxy server.
Port
Specify the port where the proxy server is listening (waiting for clients).
User name, Password, Save password, and Unlock
Enter the user name and password used to authenticate to the proxy server. If your proxy server does not require authentication, leave these edit boxes empty. You can also leave only the Password edit box empty, and the FTP client will ask you to enter the password just before connecting to the FTP server. If you want to save the password in the proxy server settings, check the Save password check box. IMPORTANT: You should protect your saved passwords with the Master Password; otherwise, they can be easily displayed in this dialog or decrypted by malicious software that has infiltrated your computer, see Using Password Manager for more information about saved passwords and the related security risks. The Unlock button is displayed when you need to enter the Master Password to access the password. To clear an inaccessible password, use the Clear Password command from the drop-down menu on the Unlock button. To show the password, hold Ctrl and right-click the Password edit box.
Login script
You can see the login script here for the selected FTP proxy server type (all types except SOCKS 4/4A/5 and HTTP 1.1). The login script defines how the FTP client should communicate with the FTP proxy server to connect to the target FTP server. The FTP proxy server acts as an FTP server. The FTP client connects to it and sends all required parameters: the user name and password for the proxy server (optional), the address and port of the target FTP server, and the user name and password for that FTP server. The FTP proxy server connects to the target FTP server and forwards all commands and replies between the FTP client and the FTP server. The plugin supports many FTP proxy servers, which you can choose from in the Type combo box. If your FTP proxy server is not supported, choose the User Defined type of FTP proxy server (in the Type combo box) and write your own login script (see Login Scripts for FTP Proxy Servers).
