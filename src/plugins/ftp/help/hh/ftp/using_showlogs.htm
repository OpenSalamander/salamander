Showing FTP Logs

The communication between the FTP client and the FTP server is stored in FTP logs. These logs can help you understand and solve common problems with FTP connections. See FTP Logs window for details on logs.

To show the FTP Logs window:

Menu:Plugins/FTP Client/Show Logs

To show the FTP Logs window and focus the log for the FTP connection in the panel:

Context menu:Right-click in panel and select Show Log.
