Open Salamander: Plugins: FTP Client: Dialog Boxes: Configuration

General

Use this tab to change the general behavior of the FTP Client plugin. See Configuring Plugins for general information about configuration.

Options

Show window with welcome message from server after connect
Clear this check box if you do not want to see a window with a welcome message from the FTP server immediately after you connect. The message contains the communication between the client and server up to the successful login reply from the server (you can find this communication in the FTP log as well). It usually contains general server rules, the number of connected clients, and similar information.
Accept hex escape sequences in paths (known from web browsers, e.g. "%20" to " ")
When checked, hexadecimal escape sequences (known from web browsers, for example "%20" for a space) are recognized in the Address box in the Connect to FTP Server dialog box. Otherwise, these sequences are left unchanged.
Close operation dialog automatically when operation is successfully finished in untouched dialog
When checked, the Operation dialog box is closed automatically when an operation finishes successfully and you are not actively using the dialog box (for example, clicking buttons or even just changing focus counts as using it). The dialog box is closed only when there is nothing important to review in it. Otherwise, you must close it manually.
Open Solve Error dialogs for errors automatically if operation dialog is idle
When checked, the plugin automatically opens Solve Error dialog boxes. It opens them for all errors one by one, but only if you are not currently working in the Operation dialog box. This can simplify error handling in the Operation dialog box. Otherwise, you must open Solve Error dialog boxes manually by using the Solve Error button.
Password for anonymous connections (your e-mail)
You can specify your email address here. It is used as a password for anonymous connections to public FTP servers (they usually require it but do not check it).
