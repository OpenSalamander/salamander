Getting Started with Database Viewer Plugin

With Database Viewer, you can view basic database files. You can also search within them, copy one or more items to the clipboard, and bookmark items for quick access.

Supported formats:

  • dBase II, dBase III, dBase IV, dBase V, Visual dBase 7, FoxPRO (*.DBF)
  • Comma-separated values (*.CSV)
  • Tab-delimited text files (*.TXT)

See the File Viewer section in Using Plugins for a description of basic operations with the plugin viewer.
