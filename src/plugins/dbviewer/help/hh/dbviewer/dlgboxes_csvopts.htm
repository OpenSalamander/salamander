CSV Options

You can customize how CSV files are read in this dialog.

Options

Separator: Auto-select, Tabulator, Semicolon, Comma, Space, Other
Specify the character that separates values in rows. Auto-select tries to automatically determine the separator character.
Text Qualifier: Auto-select, Double Quotes, Quotes, None
Specify whether text values are surrounded by quotes. Auto-select tries to automatically determine whether the file contains text values with or without quotes.
First Row: Auto-select, As Column Names, As Data
Select how to use the first row in the CSV file: as column names or as data. All other rows are always used as data. Auto-select tries to detect whether the first row contains column names rather than data, but this is not always possible (e.g., when all columns contain text values, it is impossible to distinguish between a value and a column name, because both are text).
Set as Default
Click this button to set the current options as the default for all future viewings of CSV files.
