Converting Text Values

Text values in database files can be stored in various code pages. To display them correctly, you may need to convert them to the ANSI code page, depending on your current regional settings. The viewer supports these conversions through the following commands:

  • Auto-Select: when checked, the viewer attempts to automatically detect the necessary conversion,
  • Don't Convert, custom conversions (defined in the CONVERT directory in the Open Salamander installation), OEM-ANSI, and ANSI-OEM: the currently active conversion is checked (Don't Convert is checked if no conversion is active); you can choose any conversion from this list,
  • Set as Default: use this command to set the current conversion as the default for all future viewing sessions (this also disables Auto-Select),
  • Next (the F8 key): try the next conversion from the menu (you can cycle through all conversions to find the one that displays the text values most clearly),
  • Previous (the Shift+F8 key): try the previous conversion from the menu.

You can find all these commands in the viewer menu Convert.
