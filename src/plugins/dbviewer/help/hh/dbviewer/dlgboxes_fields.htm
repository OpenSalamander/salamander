Open Salamander: Plugins: Database Viewer: Dialog Boxes

Fields

The fields (columns) of the displayed file are listed in this dialog box. You can see the data type, width, and number of decimal places (valid only for numbers) for each field. Select or clear the checkboxes before field names to show or hide the corresponding column in the viewer. Use the Alt+Up and Down Arrow keys to change the order of fields (columns) in the viewer.

Options

Restore Defaults
Use this button to show all fields (columns) in the viewer and restore them to their original order.
