Open Salamander: Plugins: Database Viewer: Dialog Boxes

Fields

This dialog box lists the fields (columns) of the displayed file. For each field, you can see its data type, width, and number of decimal places (valid only for numbers). Select or clear the checkboxes next to field names to show or hide the corresponding columns in the viewer. Use Alt+Up and Alt+Down Arrow keys to change the order of fields (columns).

Options

Restore Defaults
Use this button to show all fields (columns) in the viewer and restore them to their original order.
