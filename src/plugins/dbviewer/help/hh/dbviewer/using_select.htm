Selecting Items

You can select items using the mouse or keyboard. With the mouse, press and hold the left mouse button to define the first corner of the selection area—the opposite corner will follow the mouse pointer. While dragging, you can move the mouse pointer near the edge of the view to scroll the view.

With the keyboard, focus the first item and press and hold the Shift key to define the first corner of the selection area. Then, while still holding the Shift key, use the arrow keys, Home, End, Page Up, and Page Down keys to move the opposite corner of the selection area.
