Getting Started with Check Version Plugin

The Check Version plugin allows you to easily check for newer versions of Open Salamander and plugins. It connects to the ALTAP server on the Internet and retrieves information about current versions. It can check for new versions automatically (at a specified interval) and in the background (showing the window only when a newer version is available).

See the Menu Extension section in Using Plugins for a description of basic operations with the menu extension.
