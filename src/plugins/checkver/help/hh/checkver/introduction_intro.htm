Open Salamander: Plugins: Check Version: Introduction

Getting Started with Check Version Plugin

The Check Version allows you to easily check for newer versions of Open Salamander and plugins. It connects to the ALTAP server on the Internet and retrieves information about the current versions. It can check for new versions automatically (with a given period) and in the background (it shows the window only if a newer version is available).

See Menu Extension section in Using Plugins for a description of basic work with menu extension.
