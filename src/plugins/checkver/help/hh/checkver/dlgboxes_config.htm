Open Salamander: Plugins: Check Version: Dialog Boxes

Configuration of Check Version

You can customize the behavior of the Check Version plugin in this dialog. See Configuring Plugins for general information about configuration.

Options

Internet Connection Settings
Specify your Internet connection type and the protocol used to obtain data from the ALTAP server. Click the Change button to see all types in the CheckVer Internet Connection Settings dialog box.
Open Check for New Versions window on Open Salamander start
Choose the period for automatically checking for newer versions (never, every day, every week, every month, every three months, or every six months).
When Check for New Versions window is opened, hide it and perform auto-connect
When checked, the plugin automatically connects to the ALTAP server and retrieves information about newer versions. Otherwise, you must click the Check Now button in the Check For New Versions window to start checking.
Close window if no new version is found, otherwise show window
When checked, the plugin remains quiet until it finds newer versions. If new versions are available, it shows the Check For New Versions window with the available updates. When not checked, you must manually close the Check For New Versions window each time by clicking the Close button.
Filters
The Filters list box contains versions of modules you are not interested in and want to ignore. You can add either all versions of a module (if no version is specified) or just one version of a module (other versions will not be filtered). To add one or all versions of a module to this list, right-click the module name in the Log window in the Check For New Versions window when it displays the list of newer versions.
Remove Selected Item From Filters
Click this button to remove the selected item (one or all versions of a module) from the Filters list box. The item will no longer be filtered.
Check for release versions of Open Salamander and plugins
When checked, you are interested in new release versions. Otherwise new release versions are ignored.
Check for beta versions of Open Salamander and plugins
When checked, you are interested in new beta versions. Otherwise new beta versions are ignored.
Check for preview build versions of Open Salamander and plugins
When checked, you are interested in new preview build versions. Otherwise new preview build versions are ignored.
Set defaults
Choose this button to set the defaults in this dialog (depending on the selected Internet connection type).
