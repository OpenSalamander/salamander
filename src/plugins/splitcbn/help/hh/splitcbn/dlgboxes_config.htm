Split & Combine Configuration

You can customize the Split & Combine plugin in this dialog. See Configuring Plugins for general information about configuration.

Options

Include original extension to output filenames
Splitting produces files with a sequence number in the extension. You can choose whether this extension is added to or replaces the original extension.
Create batch file for combining
When checked, this plugin creates a .bat file for combining parts into the original file even without using this plugin. Moreover, some additional data is added to this .bat file: the original filename, CRC checksum, and file time. It is recommended to select this option because the original file's CRC checksum allows you to test the combined file for transfer errors.
Split to other panel
When checked, split results are placed in the other panel's path (instead of the current directory).
Split to subdirectory named by source file
When checked, split results are placed in a subdirectory with the same name as the original file.
Combine to other panel
When checked, the combined file is placed in the other panel's path (instead of the current directory).
