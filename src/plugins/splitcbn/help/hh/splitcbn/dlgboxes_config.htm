Split & Combine Configuration

You can customize Split & Combine plugin in this dialog. See Configuring Plugins for general information about configuration.

Options

Include original extension to output filenames
Results of splitting are files with a sequence number in the extension. You can choose here whether this extension is just added or whether it replaces the original extension.
Create batch file for combining
When checked, this plugin creates a .bat file for combining parts to the original file even without use of this plugin. Moreover, some additional data is added to this .bat file: original filename, CRC checksum, and filetime. It is recommended to select this option because the original file CRC checksum enables you to test the combined file for transfer errors.
Split to other panel
When checked, split results are placed to the other panel path (instead of the current directory).
Split to subdirectory named by source file
When checked, split results are placed to a subdirectory with the same name as original file.
Combine to other panel
When checked, the combined file is placed to the other panel path (instead of the current directory).
