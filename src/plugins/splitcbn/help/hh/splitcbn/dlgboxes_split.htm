Open Salamander: Plugins: Split & Combine: Dialog Boxes

Split

Use this dialog box to split a file into parts.

Options

Split to
Specify here the directory where you want to place the split parts of the file. See Split & Combine Configuration for options related to generating the path to this directory.
Size of each part
Specify the maximum size of one part of the split file. You can choose a predefined value from the combo box below, or you can enter your own number and specify the size unit (B, KB, MB, etc.). The size of the last part is displayed.
Number of parts
Enter here the requested number of parts of the split file.
Configure
Opens Split & Combine Configuration. You can select more options for splitting here.
