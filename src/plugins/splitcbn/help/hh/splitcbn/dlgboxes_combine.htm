Open Salamander: Plugins: Split & Combine: Dialog Boxes

Combine

Use this dialog box to combine all parts back into the original file and check the resulting file for transfer errors (using the CRC checksum).

Options

Partial files, Up, Down, Add, and Remove
Contains all parts of the original file. You can reorder these parts using the Up and Down buttons. You can also add and remove parts using the Add and Remove buttons. Parts are joined into the original file in the same order as they are displayed in this list.
CRC
Calculates the CRC checksum of the joined parts and compares it with the original file's CRC (if available - it is stored in the generated .bat file). Use this to find out whether you have correctly ordered the parts of the original file. This CRC test is always performed when combining parts into the original file (after you choose the OK button), so you do not need to test it explicitly using this button.
Combine to
Specifies the filename of the resulting file. See Split & Combine Configuration for options related to generating this filename.
