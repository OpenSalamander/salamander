Opening a Directory You've Worked In Recently

The list of working directories provides an easy way to access directories you've worked in recently. To open a recent directory, open the list and choose the directory you want.

To open the history list:

Menu:Commands/List of Working Directories
Shortcut key:Alt+F12
Mouse:In the Directory Line, click the drop-down arrow between the current directory and the free space area.
