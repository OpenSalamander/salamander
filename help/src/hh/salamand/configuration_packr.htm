Open Salamander: Dialog Boxes: Configuration

Packers in Pack Dialog Box

Allows you to manage packers used by the Pack command.

Dialog Box Options

Name
Displays a list of all packers used by the Pack command. You can reorder the names according to the packers you use most often.
Pack with
Specifies the packer used for the selected packer name. It can be either an external program or a plugin.
Default extension
Specifies the extension used when a new archive is created with the Pack command.
Pack to archive
When an external program is used for packing, Command specifies the file name of the external archiver to use. Using a variable from External Archivers Locations is recommended when the packer is known in Open Salamander. Arguments are the parameters passed to the external program.
Pack to archive and then delete from disk
When an external program is used for packing and supports deleting files, Command specifies the file name of the external archiver to use. Using a variable from External Archivers Locations is recommended. Arguments are the parameters passed to the external program.
Support long names
Check this check box when the external archiver supports long file names. Otherwise, clear this check box and Open Salamander uses MS-DOS 8.3 file names.
Need List of Files in ANSI Charset
Check this check box if the external program used for packing and deleting files requires a list of files in ANSI charset (some Win32 archivers). Clear this check box if it requires a list of files in OEM charset.
