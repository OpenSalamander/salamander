Code Page Conversion Tables

Choose the code page conversion tables in this dialog box. These tables are used by the Internal Viewer, the Convert command, and some plugin viewers. They allow you to convert text stored in a character encoding other than ANSI (e.g. EBCDIC, MAC, or MS-DOS) to ANSI encoding so it can be displayed properly in Windows.
