Open Salamander: Dialog Boxes: Configuration

Archivers

Allows you to change how archivers behave.

Dialog Box Options

Use simple icons in archives
When checked, simple symbols are shown in archives instead of the default icons provided by the system.
Pack to other panel
When checked, the default destination directory for a created archive is set to the target (inactive) panel instead of the source (active) panel.
Unpack to other panel
When checked, the default destination directory for an unpacked archive is set to the target (inactive) panel instead of the source (active) panel.
Unpack to subdirectory named by archive
When checked, the default destination directory ends with the name of the unpacked archive; otherwise, the destination directory is set only to the active or inactive panel according to the Unpack to other panel check box.
