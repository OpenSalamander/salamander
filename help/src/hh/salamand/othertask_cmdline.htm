Working with Command Line

When the Command Line becomes active, you can type any command for the system shell and execute it by pressing Enter. To insert the name of the focused file or directory from the panel into the command line, use the following shortcut keys:

Press To
Ctrl+EnterInsert the name of the focused file or directory in the active panel.
Ctrl+Shift+EnterInsert the DOS name of the focused file or directory in the active panel.
Ctrl+SpaceInsert the full name of the current directory in the active panel.
Ctrl+Shift+SpaceInsert the DOS name of the current directory in the active panel.
Ctrl+[Insert the full name of the current directory in the left panel.
Ctrl+Shift+[Insert the DOS name of the current directory in the left panel.
Ctrl+]Insert the full name of the current directory in the right panel.
Ctrl+Shift+]Insert the DOS name of the current directory in the right panel.

On the General page in the Configuration dialog, you can choose whether the system command shell window is closed after the command is executed (Close shell window after command execution (in Command line)). If you execute the command with Alt+Enter, this setting is reversed for that command.

The last 30 commands you executed are stored in the Command line history. Use Ctrl+Up and Ctrl+Down to scroll through this history. If the Command Line is active and you need to switch to another directory or execute a file in the panel, use Shift+Enter, or press Enter if the Command Line is empty (e.g. there is nothing to execute).

Command Line Length Limits

The maximum length of a command with arguments depends on the Windows version. Open Salamander executes commands through the system command shell specified by the COMSPEC environment variable; usually this is cmd.exe or command.com. The following table shows the maximum lengths.

Windows VersionMaximum Length
Windows 2000 4096
Windows XP 8192
Windows XP x64 8156 (for COMSPEC=C:\Windows\system32\cmd.exe; longer COMSPEC, shorter limit)
Windows Vista 8156 (for COMSPEC=C:\Windows\system32\cmd.exe; longer COMSPEC, shorter limit)
Windows 7 8156 (for COMSPEC=C:\Windows\system32\cmd.exe; longer COMSPEC, shorter limit)
