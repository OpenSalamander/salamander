Open Salamander: Dialog Boxes: Configuration

Unpackers in Unpack Dialog Box

Allows you to manage unpackers used by the Unpack command.

Dialog Box Options

Name
Displays a list of all unpackers used by the Unpack command.
Unpack with
Specifies the unpacker used for the selected unpacker name. It can be either an external program or a plugin.
File masks
File masks used to choose an unpacker for the selected archive when the Unpack command is used. You can also use the wildcard character '#' in these file masks. It stands for any digit ('0' ... '9').
Unpack archive
When an external program is used for unpacking, Command specifies the file name of the external archiver to use. Using a variable from External Archivers Locations is recommended when the unpacker is known in Open Salamander. Arguments are the parameters passed to the external program.
Support long names
Check this check box when the external archiver supports long file names. Otherwise, clear this check box and Open Salamander uses MS-DOS 8.3 file names.
Need List of Files in ANSI Charset
Check this check box if the external program used for unpacking files requires a list of files in ANSI charset (some Win32 archivers). Clear this check box if it requires a list of files in OEM charset.
