Open Salamander: Working with Windows and Panels

Setting Visibility of Window Components

You can customize the appearance of Open Salamander by setting the visibility of window components: the Top toolbar, the Plugin Bar, the User Menu Bar, the Hot Path Bar, the Drive Bar, the Two Drive Bars, the Middle toolbar, the Command Line, and the Bottom toolbar. You can also lock the toolbars and show or hide text labels in the User Menu Bar. If you want to see what the window components look like, see the screenshot and description in the chapter Main Window Components.

All of the commands described here can be found on the Options/Show menu.
