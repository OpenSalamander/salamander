Finding a Shortcut or Link Target

This command lets you find the target of the focused shortcut (.lnk file) or link (junction point or symbolic link). If the shortcut or link target is a file, it is focused in the current panel. If the shortcut or link target is a directory, the path in the current panel changes to that directory.

To find a shortcut or a link target:

  1. Focus a shortcut (.lnk file) or a link (it has an icon with a link overlay) in the panel.
  2. From the Commands menu, choose Go to Shortcut or Link Target (Ctrl+T), or click the Go to Shortcut or Link Target button on the Top or Middle toolbar. For a shortcut to a directory, you can also press Enter or double-click it.
