Opening Previous or Next File from Panel or Find Window

When a panel or the Find window's found files list shows multiple files in a directory, you can use the View command on the first one and then open all the others in the same viewer window one by one with the following commands:

  • Previous (the Backspace key): open the previous file,
  • Next (the Space key): open the next file,
  • Previous Selected (the Ctrl+Backspace key): open the previous selected file,
  • Next Selected (the Ctrl+Space key): open the next selected file,
  • First (the Shift+Backspace key): open the first file,
  • Last (the Shift+Space key): open the last file.

Note: all these commands work only until you change the contents of the panel or the Find window from which the viewer was opened.

You can find all the described commands in the viewer submenu: File/Other Files.
