Open Salamander: Working with Windows and Panels

Setting Visibility of Panel Components

You can customize the appearance of the left or right panel by setting the visibility of its components (the Directory Line, the Header Line, and the Information Line). If you want to see what the panel components look like, see the screenshot and description in the chapter Panel Components.

To set the visibility of the left panel components, use the three menu items on Left/Show. To set the visibility of the right panel components, use the three menu items on Right/Show.
