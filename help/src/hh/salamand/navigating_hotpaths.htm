Open Salamander: Navigating Through Directories

Using Hot Paths

Hot Paths provide quick access to frequently visited directories. You can define up to 30 Hot Paths. Each Hot Path has a friendly name and can point to a local, network, or UNC path, an archive path, or a plugin file system path. The first ten Hot Paths can be accessed with keyboard shortcuts.

To define a new Hot Path:

Menu:Open Configuration/Hot Path dialog box. Select a Hot Path position in the Defined Hot Paths list. Enter a name for the new Hot Path. In the Path text box, type the path for the new Hot Path. Choose the OK button.
Shortcut key:In the active panel, open the directory you want to set as a Hot Path. Press Ctrl+Shift+number key, where the number is 0 to 9. Or press Ctrl+Shift+= to add the current directory to Hot Paths. This works only if a Hot Path position from 11 to 30 is free.
Mouse:In the panel, open the directory you want to set as a Hot Path. Right-click the current directory in the Directory Line and select Assign Hot Path. Then choose the Hot Path position you want to assign it to. Or choose the New Hot Path command to add the current directory to Hot Paths. This works only if a Hot Path position from 11 to 30 is free.

To access a defined Hot Path:

Menu:Open the Left or Right menu, select Go To, and choose the Hot Path you want to use.
Change Drive Menu:Defined Hot Paths are listed in the Change Drive Menu. You can choose which Hot Paths should be listed in the Change Drive Menu (see Configuration/Hot Path).
Shortcut key:Press Ctrl+number key, where the number is 0 to 9 (or Shift+number key if the check box Use Shift+number for go to Hot Path in Configuration/Panels is selected), to change the current directory to the chosen Hot Path. If you want to see the list of all defined Hot Paths, press Shift+F9.
Toolbar:Choose the Go To Hot Path button (with drop-down arrow) on the Top or Middle toolbar and choose the Hot Path you want to go to.
