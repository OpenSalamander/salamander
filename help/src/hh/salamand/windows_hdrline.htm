Open Salamander: Window Components

Header Line

The Header Line displays column headings when the panel is in detailed mode.
You can:
  • Click a column heading to sort panel items by that column. Click the same heading again to reverse the sort order. Only some columns can be sorted.
  • Drag the Header Line dividers that separate column headings to set the width of each column. Dragging is not available when a column is in Automatic Column Width mode; the width of the column fits the maximum width of the column entries.
  • Right-click a column heading, then click Automatic Column Width or Smart Column Mode (only on the Name column) to choose the mode for that column. See Configuration/Views for more information.
