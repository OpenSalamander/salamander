Restoring Network Connections

If a network connection is not accessible during logon, the system temporarily disables it. To restore such a network connection, change the drive to the appropriate disabled network volume with the Alt+F1 or Alt+F2 key. If the network volume becomes inaccessible while you are working and you try to access it, the system may take a long time to detect the error. If this happens, you can press the Escape key to continue working in Open Salamander (waiting for the system error runs in a separate thread).
