Open Salamander: Dialog Boxes: Configuration

Hot Paths

Allows you to manage Hot Paths used to access frequently visited directories.

Dialog Box Options

Defined Hot Paths
Lists all the Hot Path names you have defined. Checked Hot Paths are displayed in the Change Drive Menu.
Path
Specifies the directory path for the selected Hot Path. It can be a path to a disk, archive, or plugin file system. You can use symbolic variables such as $(WinDir), $(SysDir), and $(SalDir), which expand to the Windows directory, System directory, and Salamander directory. You can also enter $[ENV_VAR] to expand the environment variable ENV_VAR. If you want to enter the character $ in the path, enter it twice.
Open this page when Hot Path is assigned from the panel
When checked, this configuration dialog box opens when a Hot Path is defined from the panel (use Ctrl+Shift+number to assign a Hot Path).
