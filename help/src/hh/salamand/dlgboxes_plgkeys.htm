Open Salamander: Dialog Boxes

Plugin Keyboard Shortcuts

Use this dialog box to assign shortcut keys to plugin menu commands (see the Menu Extension section in Using Plugins).

Dialog Box Options

Menu Items
Displays a list of all plugin menu commands with their currently assigned shortcut keys.
Press new shortcut key, Assign
Select the menu command to which you want to assign a new shortcut key. Then go to the Press new shortcut key box and press that shortcut key. Click the Assign button to assign the new shortcut key.
Clear
Select the menu command whose shortcut key you want to clear. Click the Clear button to remove the assigned shortcut key.
Reset
Restores the original shortcut-key assignments for all menu commands of this plugin.
