Open Salamander: Dialog Boxes: Configuration

Viewers

Allows you to associate file extensions with viewer plugins or external viewers.

Dialog Box Options

File masks priority list
Lists all extensions associated with viewers. Multiple extensions separated by semicolons (;) can be associated with one viewer.
Associated viewer
Specifies the viewer associated with the selected extensions. It can be an external viewer, Internal Viewer (text/hex), or a plugin.
Command
Specifies the path to the external program used to display file content.
Arguments
Specifies parameters passed to the external viewer.
Initial directory
Specifies the initial directory for the external viewer.
