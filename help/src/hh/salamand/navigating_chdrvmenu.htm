Open Salamander: Navigating Through Directories

Change Drive Menu

Use the Change Drive command on the Left or Right menu to open the Change Drive Menu. It lets you change the current directory in the panel. The Change Drive Menu contains:
  • local drives (floppy disk drives, CD-ROM drives, hard disk drives, etc.),
  • network drives,
  • opened plugin file systems,
  • the Documents item,
  • the Network item,
  • the list of plugin file systems,
  • the As Other Panel item,
  • and the list of Hot Paths.

Local Drives and Network Drives

Use one of these items to change the current directory to the last visited (or root) directory on the chosen drive. You can use drive letters as keyboard shortcuts for drives in the menu (these letters are underlined). Note that the menu contains the types of floppy disk drives (5.25", 3.5", or 8"), the labels of hard disk drives and CD-ROM drives, free space on hard disk drives, and network paths for network drives. You can select which drives are visible and separate groups of drives; see Configuration/Change Drive Menu and Drive Bar.

Opened Plugin File Systems

Use one of these items to change the current directory to the last visited directory in the chosen plugin file system (for example, an FTP or SCP/SFTP server). An opened plugin file system from the other panel is disabled because it cannot be opened in the active panel at the same time.

The Documents Item

Use this item to change the current directory to the Documents folder. This item is optional - see the Documents check box in Configuration/Change Drive Menu and Drive Bar.

The Network Item

Use this item to change the current directory to a shared directory on a computer on the network. This item is optional - see the Network check box in Configuration/Change Drive Menu and Drive Bar.

The List of Plugin File Systems

Use one of these items to open a plugin file system in the panel. If you do not find a plugin file system in this list, find the appropriate plugin in the Plugins Manager dialog box and select the Show FS item in Change Drive menu and Drive bar check box. See Opening Plugin File Systems for details.

The As Other Panel Item

Use this item to change the current directory to the current directory of the other panel. This item is optional - see the As Other Panel check box in Configuration/Change Drive Menu and Drive Bar.

The List of Hot Paths

Use one of these items to change the current directory to the chosen Hot Path. For details on Hot Paths, see Using Hot Paths.

Location

Menu:Left/Change Drive for the left panel and Right/Change Drive for the right panel.
Shortcut key:The Alt+F1 key for the left panel and the Alt+F2 key for the right panel.
Toolbar:Choose the Change Drive button on the Panel toolbar in the Directory Line of the panel.
