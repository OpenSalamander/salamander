Viewing a File

This command is used to display the contents of a file or document. Different viewers can be associated with different file extensions (for example, a text viewer for *.txt and a bitmap viewer for *.bmp). See Viewers configuration. Two different viewers can be associated with one extension: Viewer and Alternate Viewer (for example, you can view a *.htm file either in Internet Explorer Viewer or in Internal Viewer).

To view a file:

  1. Focus the file you want to view.
  2. Choose View or Alternate View command:
    Menu:Files/View or Files/Alternate View
    Shortcut key:F3 or Alt+F3
    Toolbar:Choose the View button on the Top, Middle, or Bottom toolbar.

To view a file using a non-associated viewer:

  1. Focus the file you want to view.
  2. Choose a viewer from the View With submenu (it contains all viewers from Viewers configuration):
    Menu:Files/View With
    Shortcut key:Ctrl+Shift+F3
