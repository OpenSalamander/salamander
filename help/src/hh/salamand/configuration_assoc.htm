Open Salamander: Dialog Boxes: Configuration

Archives Associations in Panels

Allows you to associate extensions with archivers.

Dialog Box Options

File Extensions
Displays a list of extensions associated with archivers. Multiple extensions can be associated with one archiver. Extensions are separated by semicolons (;), and the '#' character stands for any digit ('0' ... '9').
List and Unpack
Displays the archiver name associated with the selected extensions in File Extensions. This archiver is used for listing and unpacking archives.
Delete and Pack
Displays the archiver name associated with the selected extensions in File Extensions. This archiver is used for deleting files from archives and packing files into archives.
