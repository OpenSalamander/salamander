Open Salamander: Basic Working with Files and Directories

Starting an Application or Opening a Document

You can use Open Salamander to start applications. You can start an application by opening a program file or document from the panel, Command Line, or User Menu. Program files almost always have the .EXE, .COM, .PIF, .CMD, or .BAT filename extension. Document files are associated with applications and are represented by special icons in the panel.

To start an application or open a document:

Using the panel:Focus the filename in the panel and press Enter, double-click the filename, or open the context menu (right-click or Shift+F10) and choose Open.
Using the Command Line:Type the filename on the Command Line and press Enter. See Working with Command Line.
Using the User Menu:You can place frequently opened documents or applications on the User Menu. See Using the User Menu.

To open a document with a particular application, drag the document filename onto the application. The application may be a file in the panel, a button on the User Menu Bar, or an icon on the Windows desktop.
