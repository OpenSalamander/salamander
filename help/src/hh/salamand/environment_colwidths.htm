Setting Column Width

The detailed and types views, as well as your own detailed views, can contain any of the standard columns - name, extension, DOS name, size, type, last write date, last write time, and attributes. Each column in each view in each panel has its own width. A column width can be automatic, automatic in smart mode, or fixed.

A column with automatic width adjusts its width according to the longest current value in the column, so all values in the column are fully visible.

Automatic column width in smart mode can be set only for the name column. Unlike regular automatic width, it tries to minimize horizontal scrolling in the panel. It should prevent other columns from disappearing beyond the right edge of the panel when one name in the panel is very long (when the name column with automatic width is wider than the panel). This means that the name column can be narrowed (the longest names in the column may be truncated) to make all other columns visible.

A column with fixed width uses one specified width for all possible values, so longer values may be truncated.

You can set the column width type from the column's right-click context menu in the Header Line of the panel - the item Automatic Column Width (selected = automatic width, cleared = fixed width) and the item Smart Column Mode (selected = automatic width in smart mode, cleared = automatic or fixed width). You can also toggle Smart Mode by clicking the Smart Mode button on the Top or Middle toolbar, or on the Left and Right panel toolbars.

To change the width of a fixed-width column, drag the right side of the column in the Header Line with the mouse. If you want to set the column width in pixels, see Configuration/Views (menu: Options/Configuration/Views).
