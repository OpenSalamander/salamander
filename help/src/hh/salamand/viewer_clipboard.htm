Open Salamander: Using Internal Viewer

Copying Text to Clipboard

You can copy selected text from the viewer to the clipboard. If you are using text conversion (see Converting Text), the text is copied after the conversion.

When Auto-Copy Selection to Clipboard on the viewer's Options menu is checked and you select text, the selected text is automatically copied to the clipboard.

To copy selected text to the clipboard:

  1. Select the text you want to copy to the clipboard. See Selecting Text for details.
  2. Copy selected text to the clipboard:
    Viewer menu:Edit/Copy
    Viewer shortcut key:Ctrl+C
    Viewer context menu:Copy
