Using Password Manager

Open Salamander can protect sensitive information such as FTP or WinSCP passwords with a strong AES cipher. To protect this information, you need to set a Master Password. If a Master Password is not set, stored passwords can easily be displayed in dialog boxes or decrypted by malicious software running on your computer.

If you set a Master Password, each new instance of Open Salamander will ask you to enter it the first time it needs to access protected information. Later, you can change or remove the Master Password. If you remove the Master Password, sensitive information will no longer be protected.

To set the Master Password:

  1. Open Options/Configuration/Security dialog box.
  2. Set the Use Master Password option and choose your Master Password. IMPORTANT: If you forget your Master Password, we will not be able to recover it, and all protected sensitive information, such as FTP or WinSCP passwords, will be lost.

To change the Master Password:

  1. Open Options/Configuration/Security dialog box.
  2. Click the Change Master Password button.
  3. Enter the current and new Master Password.

To remove the Master Password:

  1. Open Options/Configuration/Security dialog box.
  2. Clear the Use Master Password option and enter the current Master Password.

To enter the Master Password:

  1. Open Salamander will ask you to enter the Master Password when it needs to access protected information.

Note: Avoid weak Master Passwords. Strong passwords contain at least six characters and include lowercase and uppercase letters, numbers, and special characters such as punctuation, symbols, and accented letters.
