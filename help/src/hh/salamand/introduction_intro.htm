Getting Started with Open Salamander

Open Salamander lets you organize files and directories using the convenient double-panel layout (introduced in Norton Commander). You can use Open Salamander to create and remove directories; move, copy, and delete files; connect to directories shared over the network; share directories; secure files and directories; change the case of file names; convert files (character encoding, line endings); compare directories; find files; make file lists; and view files in almost any format (jpeg, gif, png, html, doc, xls, pdf, dwg, dgn, eps, csv, dbf, mp3, etc.). You can also work with many types of archives (ZIP, RAR, 7-ZIP, TAR, GZIP, etc.), FTP, SCP, and SFTP servers, Windows Mobile devices, the Windows Registry, and ISO images; undelete (recover) permanently deleted files; shred files (irreversible delete) and clean free disk space; use the batch renamer; compare files (visual file comparison); calculate/verify SFV/MD5 checksums; split/combine files; and perform other disk, directory, and file management tasks.
