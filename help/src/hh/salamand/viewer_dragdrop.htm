Open Salamander: Using Internal Viewer

Drag & Drop

You can copy selected text from the viewer to any application (e.g. Mozilla Firefox, Microsoft Word) using drag & drop. If you are using text conversion (see Converting Text), the text is copied after the conversion.

To copy selected text using drag & drop:

  1. Select the text you want to copy. See Selecting Text for details.
  2. Move the mouse pointer over the selected text, press and hold the left mouse button, drag the pointer to the place where you want to copy the text, and then release the mouse button.
