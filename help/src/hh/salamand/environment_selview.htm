Open Salamander: Working with Windows and Panels

Selecting Current View

Open Salamander offers six view types: brief, detailed, icons, thumbnails, tiles, and types. The brief view shows only icons and names. The detailed view shows icons, names, DOS names, sizes, types, last write date&time, and attributes. The icons view shows larger icons (32 x 32 pixels) and names. The thumbnails view shows thumbnails (small previews of pictures, drawings, and documents; the thumbnail size can be set in Configuration/Appearance) and names. The tiles view shows even larger icons (48 x 48 pixels in Windows XP and later, 32 x 32 on earlier versions of Windows), names, sizes, and last write date&time. The types view is the detailed view with the type column visible.

You can change the parameters of the detailed and types views and define your own detailed views; see Configuration/Views (menu: Options/Configuration/Views).

To change the view in the left panel, use the Left menu - the Brief, Detailed, Icons, Thumbnails, Tiles, Types, and custom view items (if any). To change the view in the right panel, use the Right menu with the same items.

You can also use the Alt+2 key (brief view), the Alt+3 key (detailed view), the Alt+4 key (icons view), the Alt+5 key (thumbnails view), the Alt+6 key (tiles view), the Alt+7 key (types view), the Alt+8 key (first of your own views), ..., the Alt+0 key (last of your own views).

To change the view with the mouse, hold down the Alt key and rotate the Mouse Wheel.

You can also change the view in a panel by using the Views button on the Top, Middle, or panel toolbar.
