Open Salamander: Advanced Working with Files and Directories

Limiting the Files and Directories to Display

You can hide some files and directories in the panel. This can make work much easier because it lets you focus on the important files and directories while hiding the rest. You have two ways to do this: define a filter or hide selected (or unselected) names. The filter affects only files. Only files matching the filter mask are displayed; all others are hidden. The filter is persistent, so you can change directories in the panel and the filter remains active. In contrast, when you hide selected (or unselected) files, the change applies only to the current directory. If you change directories in the panel, you will see all names again.

To define a filter for files displayed in the panel:

  1. Open the Filter dialog box:
    Menu:Choose Left/Filter... for the left panel or Right/Filter... for the right panel.
    Shortcut key:Ctrl+F12
    Toolbar:Choose the Filter button on the Top, Middle, or panel toolbar.
  2. In the Filter dialog box, use the Use filter option to limit the displayed files to those matching the specified file masks.

    Select the Do not use filter button to display all filenames.

  3. Choose the OK button.
  4. You can also stop using the filter by clicking the filter icon () in the Directory Line and choosing Do Not Use Filter from the context menu that appears.

To hide selected (or unselected) files and directories displayed in the panel:

  1. Select the files and directories that you want to hide (or that should remain visible).
  2. Use the Hide Selected Names (or Hide Unselected Names) command from the Edit/Advanced menu or the Top or Middle toolbar.
  3. If you want to see all names again, use the Show Hidden Names command from the Edit/Advanced menu or the Top or Middle toolbar. You can also click the filter icon () in the Directory Line and choose Show Hidden Names from the displayed context menu.
