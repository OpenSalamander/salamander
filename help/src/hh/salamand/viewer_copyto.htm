Open Salamander: Using Internal Viewer

Copying Text to File

You can copy selected text from the viewer to a file, or copy the whole file if nothing is selected. If you are using a conversion (see Converting Text), the text is copied after the conversion.

To copy selected text (or the whole file if there is no selection) to a file:

  1. Select the text you want to copy to a file. Or do not select anything if you want to copy the whole file. See Selecting Text for details.
  2. Copy text to a file:
    Viewer menu:Edit/Copy to File...
    Viewer shortcut key:Ctrl+S
    Viewer context menu:Copy to...
