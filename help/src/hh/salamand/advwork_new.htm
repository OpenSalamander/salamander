Open Salamander: Advanced Working with Files and Directories

Creating a New Object

This command lets you create a new object (folder, shortcut, various document files, and so on). Open Salamander sets focus to the newly created object, so you can easily work with it, for example, open it.

To create a new object:

  1. Open the directory in which you want the new object to appear.
  2. From the Files menu, choose New and then choose the type of object you want to create.
