Open Salamander: Dialog Boxes

Change Directory dialog box

Use this dialog box to change the current directory of the active panel.

Dialog Box Options

Change directory to
Type the name of the directory you want to change to. The name can be entered as a full or relative disk path, archive path, or plugin file system path.
Browse Menu (click the button behind the Change directory to field)
Use the Browse item to display the Browse dialog box, in which you can select a directory on disk to change to. Use the Left/Right Panel Path item to change to the directory currently opened in the left/right panel. You can also change to any Hot Path by using the Hot Paths items from this menu.
Send path directly to plugin
If you have a plugin file system open in the active panel, you can select this check box to send the specified path directly to the plugin instead of analyzing it (e.g. if you have the directory "c:\" on your Unix FTP server, you can change to this directory instead of changing to the root of the C: drive).
