Open Salamander: Working with Windows and Panels

Activating the Command Line

The Command Line can be visible all the time or appear only when you activate it (see Setting Visibility of Window Components). If you want to see what the Command Line looks like, see the screenshot and description in the chapter Main Window Components.

To activate the Command Line from the panel, press Ctrl+Tab. To return to the panel, press the same key again or press Escape.

You can also activate the Command Line with the mouse. In that case, the Command Line must be visible all the time. If it is, click it to activate it.
