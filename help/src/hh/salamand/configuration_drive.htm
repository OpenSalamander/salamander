Open Salamander: Dialog Boxes: Configuration

Drives

Specifies how Open Salamander reads icons and responds to refresh events.

Dialog Box Options

Use automatic refresh
When checked, panel refresh depends on change notifications from Windows. Otherwise, the panel is forcibly refreshed after each panel operation and when the main window is activated (when you return from another application). Overall, monitoring change notifications is the better option.
Use simple icons
When checked, only the simple symbols instead of default icons provided by the system will be shown in the panels. This is useful for slow-speed media such as floppy disks, where obtaining default icons can slow down browsing.
Network drives: Use automatic refresh
When checked, panels are refreshed when they receive change notifications from Windows (so you will see all changes on a network drive made from another computer). They are also always refreshed after each panel operation and when the main window is activated (this can be suppressed; see the next option). This is because some network drives (e.g. Samba on Linux; unfortunately, it is not possible to distinguish it from a common Windows network drive) do not send change notifications properly, so panel contents would not otherwise be updated correctly.
Network drives: Do not refresh on activation of Salamander
When checked, network drives are not refreshed when the main window is activated (when you return from another application). On some network drives (e.g. Samba on Linux), you will have to refresh panel contents manually if you turn on this option.
If path in panel is inaccessible, go to
Specifies the path to switch to if the path in the panel becomes inaccessible (for example, when you remove media from a CD/DVD drive, the network becomes unavailable, or a USB stick is unplugged).
