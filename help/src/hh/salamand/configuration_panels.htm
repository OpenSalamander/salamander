Open Salamander: Dialog Boxes: Configuration

Panels

Customize panel appearance and behavior on this page.

Dialog Box Options

Hide files and directories with hidden or system attribute (Ctrl+H)
Select this check box to hide hidden and system files in the panel. When checked and the current directory contains these files or directories, a filter symbol () appears in the Directory Line.
Include directories to select/unselect operations
This option affects the operations Select using masks, Unselect using masks, and Invert selection. See Selecting Files and Directories.
Show names
Allows you to specify how to display names of files and directories.
Show sizes
Allows you to specify how to display sizes of files and directories.
Keyboard
Redirect typing from panel to Command line (hold ALT for Quick Search)
When checked, typing is redirected from the panel to the Command Line; for Quick search you must use Alt+letter. Otherwise, typing in the panel invokes Quick search. This option is provided only for compatibility with Norton Commander. Users who do not need that compatibility should clear this check box. Quick search is a very frequently used function and should be easily accessible.
Use Shift+number for go to Hot Path (it conflicts with national keyboard layouts)
When checked, Shift+number is used for the Go to Hot Path command. Otherwise Ctrl+number must be used for the Go to Hot Path command.
Mouse
Right-click to open context menu (hold CTRL to select/unselect)
When checked, context menu appears on right-click in the panel; Ctrl+right-click will perform select/unselect operations. Otherwise right-click performs select/unselect operations and Ctrl+right-click brings context menu. See Selecting Files and Directories. This option is provided only for compatibility with Norton Commander. Users who do not need that compatibility should select this check box. A context menu on right-click is the standard behavior in Windows.
Rename by slowly clicking the name twice
When checked, you can rename files and directories directly in the panel when you click a focused name. If the name is not focused, click it once to focus it, wait a moment (to prevent opening the file or directory by double-clicking), and then click the second time to rename it.
Cancel drag&drop operations shorter than X ms
When checked, drag-and-drop operations are canceled if they are finished in less time than the value specified in the box. This helps prevent users from unwanted drag-and-drop operations.
Sorting
Sort strings with respect to Regional Settings
When checked, names in the panel are sorted with respect to Regional Settings (e.g. "ha" is less than "ch" in the Czech regional setting); otherwise, the standard ASCII table is used for sorting.
Use numerical sort for numbers contained in strings
When checked, Salamander tries to detect numbers in names and sort according to the values of those numbers. For example, when this is turned on, you will see 2.txt followed by 10.txt (2 is less than 10); if it is turned off, you'll see 10.txt followed by 2.txt (character '1' precedes '2').
Sort by Time order: newer items on top
When checked and items in panel are sorted by time, items are sorted in descending order (newer items on top).
Sort by Time: sort directories by name
When checked and items in panel are sorted by time, directories are sorted by name (only files are sorted by time).
Treat directories as if have extensions (also show extensions in Ext column)
When checked, directories are sorted as if they have extensions (normally, directory names do not have extensions). Moreover, directory extensions are displayed in a separate Ext column (show this column in Configuration/Views). If you want to see the difference, sort the panel by extension.
