Open Salamander: Dialog Boxes

Save Selection

Use this dialog box to save the current selection in the active panel.

Dialog Box Options

Save selected names to
Selection memory
The selection will be saved in selection memory (for use only inside Salamander).
Clipboard
The selection will be saved to the clipboard (the format is simple: one name per line, so you can use the selection in text editors as well).
