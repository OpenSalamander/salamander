Open Salamander: Introduction

Using Help

This is a context-sensitive help system, so you can ask for help directly from open dialog boxes, selected menu items, or selected toolbar buttons. See Accessing Help for details.

The manual is divided into several major sections:

Window Components

This section describes Open Salamander windows and controls.

Using Open Salamander

This section describes how to use Open Salamander for managing files and directories. Tasks are divided by user experience into basic and advanced tasks.

Dialog Boxes

This section describes all dialog boxes and is easy to consult when you have a specific question about a dialog option.

Shortcuts

This section contains an overview of keyboard and mouse shortcuts available in Open Salamander.

Plugins

This section describes Open Salamander plugins. Each plugin has its own help, where you can find details about its purpose, usage, configuration, and keyboard shortcuts.

Appendix

This section covers a variety of topics and can be used for general information as well as reference material.

Glossary

This section contains definitions for terms used in the documentation of Open Salamander.
