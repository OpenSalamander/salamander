Saving and Loading Selection

Saving a selection lets you use it again in the same directory or in a different directory. The selection is saved either to selection memory (for use only inside Open Salamander) or to the clipboard (as plain text, so you can use it in text editors and similar applications). The saved selection can be used in both panels.

When you want to use a previously saved selection, you can load it into the panel. The current selection can be cleared or kept. If you want to keep it, you can add, subtract, or intersect it with the loaded selection.

To save a selection:

Menu:Edit/Advanced/Save Selection
Shortcut key:Ctrl+Shift+F5

To load a selection:

Menu:Edit/Advanced/Load Selection
Shortcut key:Ctrl+Shift+F6

Remarks

These commands are useful if you want to perform a series of operations (for example, convert character sets or line endings, change the case of names, or pack to an archive) on a chosen subset of files and directories. Each operation removes the selection, so you need to restore it before the next operation; see also Restore Selection in Selecting Files and Directories. You can also use these commands when you compare two directories and need to select the same files and directories in both panels, for example, to compare their total sizes or to see whether they all exist in both panels. If not, the numbers of selected items in the panels will differ.
