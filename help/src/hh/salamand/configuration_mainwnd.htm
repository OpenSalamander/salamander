Open Salamander: Dialog Boxes: Configuration

Main Window

Settings related to the appearance of the Main Window.

Dialog Box Options

Show splash screen at startup
When checked, the splash screen with Open Salamander logo and version is displayed when starting Open Salamander.
Show icon of Open Salamander in the Status area of Taskbar
When Open Salamander is minimized, the taskbar button is removed from the taskbar. Instead, an icon is displayed in the status area of the taskbar, near the clock. Clicking this icon restores the Open Salamander window.
Display current path in main window title as
When checked, the current path in the active panel is displayed in the main window title. You can choose whether it should be shortened, shown as a full path, or displayed as only the directory name.
Custom text prefix in main window title
When checked, the specified text is used as a prefix in the main window title bar. You can use it, for example, to distinguish an instance of Open Salamander started "As Administrator". This option can be overridden using command line parameters.
Icon color
You can choose a different icon color for the main window. This is intended for situations in which the color of the default icon conflicts with icons of other applications or when you need to distinguish between multiple instances of Open Salamander (for example one of them can be started "As Administrator"). This option can be overridden using command line parameters.
Note: to change the color of the shortcut icon on your Desktop or in the Start menu, right-click it, choose the Properties command and click the Change Icon button.
