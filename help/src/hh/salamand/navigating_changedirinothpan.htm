Open Salamander: Navigating Through Directories

Changing Directory in the Other Panel

You can change the directory in the other (inactive) panel to the focused directory in the active panel. You can also locate, in the other (inactive) panel, the file that is focused in the active panel.

To change the directory or locate a file in the other panel:

  1. Focus the directory or file in the active panel.
  2. Change the directory or locate the file in the other panel:
    Shortcut key:Ctrl+Shift+Left/Right Arrow key - use the arrow that points toward the other panel to activate it. The arrow in the opposite direction does not activate the other panel.
    Toolbar:Choose the Focus Name in Other Panel button on the Top or Middle toolbar - it activates the other panel.
    Choose the Open Name in Other Panel button on the Top or Middle toolbar - it does not activate the other panel.
