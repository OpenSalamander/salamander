Open Salamander: Dialog Boxes: Find

Ignore Directory List

Use this dialog box to specify directories that should be ignored when searching for files and directories. Directories in which you start the search cannot be ignored.

Dialog Box Options

Directories to skip during search
Contains a list of ignored directories. You can enter a relative directory name (e.g. Local Settings\Temporary Internet Files), the name of a directory in the root path (e.g. \System Volume Information), or an absolute path to a directory (e.g. C:\TEMP). To add a new item, focus the empty item (at the bottom) and start typing, or press the Insert key or click the New button on the toolbar. To modify an item, click the focused item or press the F2 key or click the Modify button on the toolbar. To delete an item, press the Delete key or click the Delete button on the toolbar.
Reset
Sets ignored directories to default values.
