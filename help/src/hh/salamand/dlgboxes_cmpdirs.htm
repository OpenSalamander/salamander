Open Salamander: Dialog Boxes

Compare Directories

Use this dialog box to set the criteria for comparing directories in the left and right panels. The comparison begins by clearing the selection in both panels and selecting files that exist in only one panel.

Dialog Box Options

Compare files with same name by
Size
When checked, the larger file will be selected. Otherwise, files are not compared by size.
Date and time
When checked, the newer file will be selected. Otherwise, files are not compared by time.
Attributes
When checked, files with different attributes will be selected in both panels. Otherwise, files are not compared by attributes.
Content
When checked, files with different contents will be selected in both panels. Otherwise, files are not compared by content.
Subdirectories options
Compare subdirectories
When checked, directories that exist only in one panel are selected, and directories with different contents are selected in both panels. Otherwise, directories are ignored. Directory contents are compared using the criteria chosen in this dialog (e.g. file sizes are compared only if the Size box is selected).
Compare attributes of subdirectories
When checked, directories with different attributes will be selected in both panels. Otherwise, directories are not compared by attributes.
Select subdirectories contained only in one panel
When checked, directories that exist only in one panel will be selected.
Other options
Ignore files
When checked, files matching the specified file mask are ignored. If you want to filter the files to compare and ignore all other files, use the excluded-masks part of the file mask (e.g. |*.cpp;*.h ignores anything except *.cpp;*.h).
Ignore directories
When checked, directories matching the specified file mask are ignored.
