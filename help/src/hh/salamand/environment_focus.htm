Open Salamander: Working with Windows and Panels

Focusing an Item

A panel can contain any number of items (files and directories). If the list contains any items, one of them is focused. In the active panel, the focused item is highlighted (see Working Area of Panel for details). In the inactive panel, the focused item is not highlighted, but it is highlighted again when the panel becomes active.

You can change the focus in the list of items by choosing another item. You can do this with the mouse or the keyboard. With the mouse, just click the item you want to focus. The keyboard shortcuts are summarized in the following table.

Keyboard shortcuts:

Use To
Arrows Focus the item in the specified direction from the currently focused item.
Home Focus the first item.
End Focus the last item.
Ctrl+Home Focus the first file.
Page Up Focus the item up one page from the currently focused item.
Page Down Focus the item down one page from the currently focused item.
Alt+Down arrow key Focus the next selected item.
Alt+Up arrow key Focus the previous selected item.
