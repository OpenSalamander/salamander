Open Salamander: Basic Working with Files and Directories

Moving or Renaming Files and Directories

You can move files and directories from any local or network path to a destination directory on any local or network path, in an archive, or in a plugin file system. Moving works in both directions except for archives (moving from an archive to disk is not supported; use Copy followed by Delete instead). Moving between archives and plugin file systems is not supported; use a temporary directory to complete such operations (for example, move from the plugin file system to a temporary directory and then from that directory to another plugin file system or archive). When you move a directory, all contained files and subdirectories are moved as well.

Moving or renaming files and directories using the Move/Rename command

  1. Select the files and directories you want to move.

  2. Open the Move/Rename dialog box:
    Menu:Files/Move/Rename...
    Shortcut key:F6
    Toolbar:Choose the Move/Rename button on the Top, Middle, or Bottom toolbar.
  3. In the Move to box, specify the destination directory.
  4. If you want to specify some options (see Move/Rename dialog box), click the Options button.
  5. Choose the OK button.

Moving files and directories using drag and drop

Select the files and directories you want to move. Make sure the destination is visible. When you drag a selection to its new location, watch the mouse cursor shape. If it contains the plus sign, you are copying files and directories. If it contains the link (shortcut) sign, you are creating shortcuts to files and directories. If it contains no sign, you are moving files and directories. You can change this action by pressing and holding Shift (for moving), Ctrl (for copying), or Shift+Ctrl (for creating shortcuts). While dragging, you can move the mouse pointer near the edge of the panel to scroll the panel contents.

Moving files and directories using the clipboard

  1. Select the files and directories you want to move.
  2. Choose the Cut to Clipboard command:
    Menu:Edit/Cut
    Context menu:Right-click selected files and directories and select Cut.
    Shortcut key:Ctrl+X
    Toolbar:Choose the Clipboard Cut button on the Top or Middle toolbar.
  3. Open the directory where you want to place the selected files and directories (it can also be in an archive or plugin file system).
  4. Choose the Paste from Clipboard command:
    Menu:Edit/Paste
    Context menu:Right-click destination directory and select Paste.
    Shortcut key:Ctrl+V or Shift+Insert
    Toolbar:Choose the Clipboard Paste button on the Top or Middle toolbar.

See Using Clipboard to Perform File and Directory Operations for details.

Remarks

On drives formatted to use the Windows NT file system (NTFS), you must have permissions to move or copy a file or directory.

When you copy or move files or directories to a FAT disk, permissions are discarded. See the Preserve owners and permissions (not inherited) on NTFS drives option in the Move/Rename dialog box for details on moving between NTFS disks.
