Using Open Salamander Task List

Open Salamander Task List is intended to control all running Open Salamander tasks (version 2.52 or later). Its most important feature is that it lets you break an unresponsive task from another Open Salamander task that is still responsive. Breaking the task should open the Bug Report dialog in the target task so you can send us a Bug Report about the "hung" Open Salamander task. This should help us eliminate such bugs.

To break an unresponsive (frozen) Open Salamander task:

  1. Start a new Open Salamander task.
  2. Open the Open Salamander Task List dialog box from Help/Task List.
  3. In the List of running Open Salamander tasks box, select the unresponsive task.

    Note The current task is marked with "current process".

  4. Choose the Break button.
  5. This should open the Bug Report dialog in the selected task.
  6. Activate the Bug Report dialog box and send us a Bug Report about the "hung" Open Salamander task.
