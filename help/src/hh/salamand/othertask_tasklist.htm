Using Open Salamander Task List

Open Salamander Task List is intended to control the execution of all running Open Salamander tasks (version 2.52 or later). The most important feature is the ability to break a not-responding task (do it from another responding Open Salamander task). The break should invoke the Bug Report dialog in the target task, so you can send us a Bug Report about the "hung" Open Salamander task. This should help us remove such bugs.

To break a not-responding (frozen) Open Salamander task:

  1. Start a new Open Salamander task.
  2. Open the Open Salamander Task List dialog box: Help/Task List.
  3. In the List of running Open Salamander tasks box, select the not-responding task.

    Note The current task is marked with "current process".

  4. Choose the Break button.
  5. The break should invoke the Bug Report dialog in the selected task.
  6. Activate the Bug Report dialog box and send us a Bug Report about the "hung" Open Salamander task.
