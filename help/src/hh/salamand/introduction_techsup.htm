Open Salamander: Introduction

Technical Support

If you experience problems while using Open Salamander, our technical support team is ready to help.

Before You Contact Us

Because we have many users, please do the following before contacting us:

  • Check whether you have the most recent version of Open Salamander.
  • Check whether the information you need is already available in the Help file.

Reaching Technical Support

For technical support, use Open Salamander's Official Support Forum (forum.altap.cz) or, if you need to send sensitive data, email support@altap.cz.
