Open Salamander: Dialog Boxes: Configuration

Appearance

Allows you to change Open Salamander's appearance.

Dialog Box Options

Full row select (Detailed and Brief modes only)
When an item in the panel is focused, the entire item is highlighted. In detailed mode, all item columns are highlighted. In brief mode, the entire item column width is highlighted. The highlighted part of the item is sensitive to mouse operations. When this check box is cleared, only the item name is highlighted and sensitive to mouse operations.
Highlight focused row (Detailed modes only)
When an item in the panel is focused, the entire item is highlighted. But only the item name is sensitive to mouse operations.
Single-click to open an item (point to select)
Specifies that you want to open items by single-clicking them, just as you would click a link on a Web page. To select an item without opening it, rest your pointer on it.
Show icon tincture in the panel (system/hidden/selected/focused items)
Specifies whether an item's icon in the panel should be colored for special states of the item (such as system/hidden/selected/focused items). This makes colored items easier to distinguish from normal items.
Show panel caption in Directory line
Specifies whether to show the panel caption in the Directory Line. With the panel caption displayed, you can easily distinguish the active and inactive panels.
Show maximize/restore button in Directory line
Specifies whether to show the maximize/restore button on the right side of the Directory Line. You can easily maximize/restore the panel by clicking this button.
Panel Font
Click the Font button to change the font you want to use in the panels.
Content of Information Line
Specifies the content of the Information Line. The order of values can be specified.
Thumbnails
Specifies the size of thumbnails in the panels (in Thumbnails mode).
