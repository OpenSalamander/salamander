Open Salamander: Window Components

Working Area

Each item in a panel can be either normal or selected. One of the items has a rectangle around its name (the focus), and this item is called the focused item.

When a directory is opened, all items are in the normal state and the first item is focused. See Selecting Files and Directories for details on selecting items and Focusing an Item for details on changing the focus position.

For compatibility with old-school file managers, Open Salamander supports Full row select (see Configuration/Appearance). If you do not use this option, only the icon and file name in the working area respond to mouse clicks. To focus an item, you must point the cursor at the icon or filename.
