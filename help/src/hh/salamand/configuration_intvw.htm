Open Salamander: Dialog Boxes: Configuration

Internal Viewer

Allows you to change the appearance and behavior of the Open Salamander Internal Viewer.

Dialog Box Options

Line Ends
Each row in the text view contains one line of text terminated by one of the defined line endings. You can choose which line endings should be used. See Text Files Coding and End of Line Characters. When a check box in the group is selected, the corresponding line-ending character is used.
Window position - Save on close
When selected, the Internal Viewer window position is saved when the window is closed. When a new Internal Viewer window is opened, the last position and size are used.
Window position - Set to position of Salamander's main window
When selected, the Internal Viewer window opens with the same size and position as the main window of Open Salamander.
Set Find in the Internal Viewer to search grepped text from the Find Files dialog
When checked and you open the Internal Viewer from the Find dialog, the Find command in the viewer (Ctrl+F or F3) is preset to search for the same text as in the Find dialog (see the Containing field). This is useful when viewing the contents of found files. In the Find dialog, press F3 to open the Internal Viewer. In the Internal Viewer, press F3 again to display the first occurrence of the found text.
Tab Size
Type the number of spaces to display instead of a tab character.
Force Text mode for files
All files matching specified file masks are displayed in Text mode.
Force Hex mode for files
All files matching specified file masks are displayed in Hex mode.
Font
Click the Font button to change the font you want to use in the Internal Viewer window.
Colors
Allows you to specify the colors of normal and selected text in the Internal Viewer window.
