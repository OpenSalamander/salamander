Opening System Folder

You can open special folders such as Computer, Recycle Bin, Control Panel, or Network directly from Open Salamander by using the Open Folder submenu on the Commands menu.

You can also open the current directory in Windows Explorer. Use Shift+F3, the Commands/Open Folder/Active Folder command, or the Open Active Folder button on the Top or Middle toolbar.
