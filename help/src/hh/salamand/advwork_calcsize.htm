Calculating Directory Sizes

This command calculates the total size of files and subdirectories contained in directories. It applies to all directories in the active panel, and the current selection is ignored. The calculated sizes are displayed in the Size column in the panel. This is useful if you need to find the largest subdirectories. After the sizes are calculated, you can sort the panel contents by Size.

Press the Space key to select a single directory and calculate its size.

To calculate directory sizes:

Menu:Commands/Calculate Directory Sizes
Shortcut key:Ctrl+Shift+F10
Toolbar:Choose the Calculate Directory Sizes button on the Bottom toolbar.
