Open Salamander: Other Tasks

Accessing Help

There are many ways to access Help to find answers to questions about Open Salamander and information about keywords. Some of the most common and useful methods are described below.

  • Press F1 to display help on a topic associated with the currently opened window or dialog box.
  • Press Shift+F1 in Open Salamander's main window. The mouse cursor changes to the help cursor, and you can select any visible object in the user interface, such as a menu item, toolbar button, or window. This opens Help on a topic that describes the selected item.
  • Open the Help menu from Open Salamander's main window. Select one of the following items: Contents, Index, Search, and Keyboard Shortcuts.
  • Click the Help button in a dialog box to display help on a topic associated with the currently opened dialog box.

Tips

To switch between Open Salamander and the Help window, press Alt+Tab or use the Windows taskbar. If you keep Help open, you can immediately return to the last topic you were viewing.
