Open Salamander: Dialog Boxes: Configuration

Icon Overlays

Specifies which icon overlays are displayed in panels. Icon overlays are small images placed in the lower-left corner of a file icon (for example, a small arrow that indicates the file is a shortcut).

Dialog Box Options

Display custom icon overlays (provided by shell extensions)
When checked, all checked icon overlay handlers from the Custom Icon Overlay Handlers list are used and their icon overlays are displayed in panels. Otherwise, no icon overlay handlers are used.
Custom Icon Overlay Handlers
Contains a list of all available custom icon overlay handlers. Clear the check boxes for handlers that should not be used so their icon overlays are not displayed in panels. This list is disabled when the Display custom icon overlays box is not checked.
