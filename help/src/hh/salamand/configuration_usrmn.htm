Open Salamander: Dialog Boxes: Configuration

User Menu

Allows you to manage User Menu commands used to execute external programs.

Dialog Box Options

Menu Contents
Lists all the User Menu commands you have defined. Placing an ampersand (&) before a letter in the menu item text makes the letter an accelerator key.
Submenu
When checked, the current command becomes the start of a submenu. The name of the command is used as the name of this submenu. All commands between the current command and the Submenu End command (which is added automatically) are placed in the submenu. Submenus can be nested, so you can create any structure in the User Menu. To move an existing menu command to the submenu: focus this command and use buttons with arrows in the Menu Contents toolbar or the Alt+Up and Down Arrows keys.
Separator
When checked, the name of the command will be ignored and the item signifies a separator in the User Menu and in the User Menu Bar.
Change Icon
The icon associated with the command. You can change this icon by clicking the Change Icon button.
Command
Specifies the path to the external program to execute.
Arguments
Specifies additional arguments for the external program each time you start it. The maximum length of a command with arguments depends on the Windows version and on whether you execute the command through the shell (see the Execute through shell check box later on this page). See Customizing User Menu for an overview of the limits.
Initial directory
Specifies the working directory used for the external program.
Execute through shell
When checked, the command is executed through the system command shell. Executing through the system shell is useful for console-oriented applications whose output you want to see, and for execution queues (pipes, redirected input and output, etc.). Otherwise, the command is executed directly from Open Salamander as a new process. Direct execution is good for windowed applications.
Open shell window
When checked, the command shell window opens when the command is executed.
Close shell window
When checked, the command shell window associated with the tool closes when you close the executed program.
Show item in User Menu bar
When checked, the User Menu command is shown in the User Menu Bar.
