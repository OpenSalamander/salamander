Starting Open Salamander with Parameters

Open Salamander supports command-line parameters for specifying directories to open, a configuration file to import, and more.

Syntax

SALAMAND.EXE [-L directory] [-R directory] [-A directory] [-C reg_file] [-I icon_index] [-T title_prefix] [-O] [-P panel_index]

Parameter Description
-L pathSpecifies the path for the left panel. It works with full or relative disk paths, archive paths, and plugin file system paths.
-R pathSpecifies the path for the right panel. It works with full or relative disk paths, archive paths, and plugin file system paths.
-A pathSpecifies the path for the active panel. It works with full or relative disk paths, archive paths, and plugin file system paths. This parameter is ignored when the -L or -R parameter is specified.
-C reg_fileSpecifies the exported configuration that will be imported to the registry before loading configuration from the registry. If you do not specify the full path to the configuration file, Open Salamander searches for it in the installation directory and, in Vista or later, also in the application data directory (typically C:\Users\<user>\AppData\Roaming\Open Salamander)
-I icon_indexSpecifies the icon color that will be used for the main window. 0 means the default icon, 1 means the red icon, 2 means the green icon, and 3 means the blue icon. You can also change the icon color in configuration of main window.
-T title_prefixSpecifies the text prefix displayed in the title bar of the main window. To suppress the text prefix, use the "" parameter. You can also change the prefix in configuration of main window.
-OSalamander will behave as if the Allow only one instance of Salamander at one time option is checked. This does not change the stored configuration value.
-P panel_indexSpecifies the panel that will be activated. 0 means the default panel, 1 means the left panel, and 2 means the right panel.

Examples

  • To open Open Salamander with the "C:\Program Files" directory in the left panel:

    salamand.exe -L "C:\Program Files"

  • To open Open Salamander with a personal configuration stored in myconfig.reg:

    salamand.exe -C "myconfig.reg"

  • To open Open Salamander with the red icon and the ADMIN prefix in the title bar:

    salamand.exe -I 1 -T "ADMIN"
