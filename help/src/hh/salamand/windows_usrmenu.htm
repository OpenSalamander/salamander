Open Salamander: Window Components

User Menu Bar

The User Menu Bar contains items from the User Menu and is intended for quick access to those commands. It can display either icons only or icons with text labels.

You can:
  • Click a toolbar button once to carry out the action represented by the corresponding menu item.
  • Drag the toolbar to another location.
  • Drag a file to the User Menu Bar to add a new item.
  • Drag a file or directory to a User Menu Bar button to execute that command with the dragged item as a parameter.
  • Right-click the toolbar and then click Customize Toolbar to customize the toolbar buttons, or click Text labels to show or hide text labels next to the icons.
