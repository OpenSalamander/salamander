Open Salamander: Basic Working with Files and Directories

Quick Search for a File or Directory Name

You can quickly find any desired name in the list of files and directories. Start typing the name, and the first item with the typed prefix is focused. You can extend the prefix with the Right arrow key and shorten it with the Left arrow key or Backspace. To focus the next or previous name with the same prefix, use the Down or Up arrow key. To leave quick search mode, press Escape.

While Open Salamander is in quick search mode, the following keys are used for moving through files and directories that match the quick search mask: Up, Down, Page Up, Page Down, Home, End, Shift+Up, Shift+Down, Shift+Page Up, Shift+Page Down, Shift+Home, Shift+End, Alt+Up, Alt+Down, Alt+Home, and Alt+End. Keys with the Shift modifier select or unselect files and directories, and keys with the Alt modifier move only through selected files and directories. See Main Window Keyboard Shortcuts.

Advanced Usage

When you type a slash (/), backslash (\), or less-than (<) character, it matches any part of the name (similar to '*' in file masks). A trailing dot (.) character is ignored when the name has no extension. Examples:

When you typeIt will find names Corresponding file mask
/lefile.txt, less.exe, bmp.rle, etc.*le*
pro/.htmpromote.html, prototype.htm, professional.htm, etc.pro*.htm*
/.htmany.htm, page.htm, index.html, etc.*.htm*
/g.flag, flag.txt, etc. Note: it will not find the name pic.jpg.*g.*

Note for German users: you can use the same key in both the English and German keyboard layouts, because the backslash (\) and less-than (<) characters have the same function in quick search mode.

Remarks

When the Redirect typing from panel to Command line check box in Configuration/Panels is selected, use Alt+letter to enter quick search mode.
