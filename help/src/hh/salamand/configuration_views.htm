Open Salamander: Dialog Boxes: Configuration

Views

Allows you to define the content displayed in Open Salamander panels.

Dialog Box Options

Defined Views
Lists all defined views. Details of the selected view are displayed in the rest of this dialog box. You can rename (F2), delete (Delete), and change the position of views in this list (Alt+Down or Up Arrow). Use the toolbar above the list or the keyboard shortcuts.
Available Columns
Contains a list of all columns in the selected view. Check the columns you want to see. This list is disabled when no named view is selected or when the selected view type is not Detailed.
Fixed column width in left/right panel
Only for detailed views. When checked, the fixed width of the selected column in the left or right panel can be set (usually by dragging the column's right edge in the Header Line). Otherwise, it is calculated automatically to fit the longest value in the column. You can also change the column to fixed or automatic width using the Automatic Column Width item in the right-click context menu on the column header in the Header Line.
Set smart mode: Left/Right panel
Only for detailed views. When checked and the Name column does not have a fixed width (the previous option must be turned off), Salamander narrows the Name column if needed to reduce horizontal scrolling in the panel. This helps when you have a few files with very long names that push other columns far to the right (often beyond the panel's right edge, so you must scroll right to see their values). You can turn smart mode on or off using Ctrl+N in the panel or by using the Smart Column Mode item in the right-click context menu on the Name column header in the Header Line.
