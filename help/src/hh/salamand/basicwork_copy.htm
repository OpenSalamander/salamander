Open Salamander: Basic Working with Files and Directories

Copying Files and Directories

You can copy files and directories from any local or network path to a destination directory on any local or network path, in an archive, or in a plugin file system. Copying works in both directions. Copying between archives and plugin file systems is not supported; use a temporary directory to complete such operations (for example, copy from the archive to a temporary directory and then from that directory to another archive or plugin file system). When you copy a directory, all contained files and subdirectories are copied as well.

Copying files and directories using the Copy command

  1. Select the files and directories you want to copy.
  2. Open the Copy dialog box:
    Menu:Files/Copy...
    Shortcut key:F5
    Toolbar:Choose the Copy button on the Top, Middle, or Bottom toolbar.
  3. In the Copy to box, specify the destination directory.
  4. If you want to specify additional options (see Copy dialog box), click the Options button.
  5. Choose the OK button.

Copying files and directories using drag and drop

Select the files and directories you want to copy. Make sure the destination is visible. When you drag a selection to its new location, watch the mouse cursor shape. If it contains the plus sign, you are copying files and directories. If it contains the link (shortcut) sign, you are creating shortcuts to files and directories. If it contains no sign, you are moving files and directories. You can change this action by pressing and holding Shift (for moving), Ctrl (for copying), or Shift+Ctrl (for creating shortcuts). While dragging, you can move the mouse pointer near the edge of the panel to scroll the panel contents.

Copying files and directories using the clipboard

  1. Select the files and directories you want to copy (they can also be in an archive).
  2. Choose the Copy to Clipboard command:
    Menu:Edit/Copy
    Context menu:Right-click selected files and directories and select Copy.
    Shortcut key:Ctrl+C or Ctrl+Insert
    Toolbar:Choose the Clipboard Copy button on the Top or Middle toolbar.
  3. Open the directory where you want to place the copy (it can also be in an archive or plugin file system).
  4. Choose the Paste from Clipboard command:
    Menu:Edit/Paste
    Context menu:Right-click destination directory and select Paste.
    Shortcut key:Ctrl+V or Shift+Insert
    Toolbar:Choose the Clipboard Paste button on the Top or Middle toolbar.

See Using Clipboard to Perform File and Directory Operations for details.

Remarks

On drives formatted to use the Windows NT file system (NTFS), you must have permissions to move or copy a file or directory.

When you copy or move files or directories to a FAT disk, permissions are discarded. See the Preserve owners and permissions (not inherited) on NTFS drives option in the Copy dialog box for details on moving between NTFS disks.
