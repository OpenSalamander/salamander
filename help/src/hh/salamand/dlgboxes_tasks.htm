Open Salamander: Dialog Boxes

Open Salamander Task List

Use this dialog box to break or terminate an unresponsive Open Salamander task.

Dialog Box Options

List of running Open Salamander tasks
Contains a list of all Open Salamander tasks. The current task is marked with "current process".
Highlight
Flashes the main window of the selected Open Salamander task.
Break
Breaks the selected Open Salamander task and invokes its Bug Report dialog.
Terminate
Terminates the selected Open Salamander task.
Refresh
Refreshes the list of running Open Salamander tasks.
