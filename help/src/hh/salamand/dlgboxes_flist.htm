Open Salamander: Dialog Boxes

Make File List

Use this dialog box to create a list of selected files and directories. The list can be saved to a file, copied to the clipboard, or opened in the Internal Viewer. You can also specify the format of the lines in the list.

Dialog Box Options

Line
Specify the format string for the lines in the list. Build the format string from your own text and the variables available in the context menu, which you can open by clicking the button on the right side of the Line field. You can set the width of the variable value to a fixed number of characters or to 'max' (to fit the longest value). For example: "$(FileName:20)$(TAB)$(FileSize)$(CRLF)" or "$(FileName:max)$(TAB)$(FileSize)$(CRLF)". If you need to write a dollar character ($), type it twice (e.g. "$$30 utility $(FileName)$(CRLF)"). Use the drop-down list to select previously used format strings.
Destination: Clipboard, Internal Viewer, File
Choose the destination for the list. If you want to save it to a file, also specify its filename here.
Append to file
When selected and the specified file already exists, the output will be appended to the file instead of overwriting it.
