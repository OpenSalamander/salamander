Open Salamander: Dialog Boxes: Configuration

General

Allows you to change the general behavior of Open Salamander.

Dialog Box Options

Save configuration on exit
When checked, the configuration is saved when Open Salamander exits. The configuration contains settings from the Configuration dialog, main window position, panel widths and current directories, and other options.
Clear read-only attribute when copying from CD-ROM
Files on CD-ROMs have the read-only attribute set. This check box lets you clear this attribute during the copy operation, which is useful for further processing of these files.
Allow only one instance of Salamander at one time
When checked, only one instance of Open Salamander can run. If you try to start another instance of Open Salamander, the running instance will be activated instead.
Use speaker beep to announce finishing of work in inactive window
Allows you to be notified when an operation in an inactive window is finished.
Close shell window after command execution (in Command line)
When checked, the command shell is closed after a command is executed in the Command Line. If you execute the command with the Alt+Enter key, this setting is inverted for that command.
Compare Directories: ignore time differences up to
When checked, the Compare Directories command compares files using the specified time tolerance. Use this option to compensate for differences in time accuracy across various file systems. See File Times for details.
Compare Directories: ignore time differences of exactly one or two hours
When checked, the Compare Directories command ignores time differences of exactly one or two hours. Such differences can appear because of DST (Daylight Saving Time) and different ways of storing time information on various file systems. For example NTFS uses UTC (after adjusting clocks due to DST all times on NTFS seem to be shifted because of adjusted conversion of UTC to local time) and FAT32 uses values in local time zone (there are no shifts due to DST because no conversion to local time is needed). See File Times for details.
Open files through salopen.exe (it bypasses shell extensions errors)
When checked, opening files in the panel is handled through the small program salopen.exe. This option can be useful when directories containing files you have opened might otherwise be impossible to delete.
Select also filename extension in Quick Rename and Pack commands
When checked, the whole name, including the extension, is initially selected when entering a new filename in the Quick Rename or Pack dialog boxes. Otherwise, only the name part is selected. You can use the Ctrl+A keyboard shortcut to select all.
Select also filename extension in Edit New File command
When checked, the whole name, including the extension, is initially selected when entering a new filename in the Edit New File dialog box. Otherwise, only the name part is selected. You can use the Ctrl+A keyboard shortcut to select all.
Use fast directory move on Novell Netware
When checked and you are moving a directory within a single Novell Netware drive, Salamander moves the directory simply by renaming it to the target path (this is fast, but it does not always work). Otherwise, Salamander renames only files, creates all necessary directories on the target path, and deletes them from the source directory after the contained files are moved (this can be much slower, but it always works). We recommend turning on this option and turning it off only when moving directories within one Novell Netware drive fails.
Copy files: use faster asynchronous algorithm on network (Windows 7 and later)
When checked and you are copying files to or from a network drive, Salamander uses an asynchronous copy algorithm that is faster than the conventional one (111 MB/s on GLAN instead of 86 MB/s). This advanced algorithm is available only on Windows 7 and later. Otherwise, Salamander copies files using the conventional algorithm. This option also affects moving files when you are not moving them within a single volume (in that case the operation is not just a rename, but a copy and delete). The asynchronous copy algorithm is also optimized for network drives accessible via VPN (Virtual Private Network). It uses smaller blocks (the size depends on the current copy speed), so progress is smoother and you can cancel the operation instantly.
Keep environment variables updated to system values
When checked, Salamander reads system environment variables at startup and whenever the system environment variables change. Values of environment variables inherited from the parent process are overwritten by system values. Variables that do not exist in the system remain untouched. Clear this option to use the inherited environment variables in the running Salamander process and in all processes started from it.
