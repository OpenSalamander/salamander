Compressing and Encrypting Files and Directories

You can compress or encrypt files and directories on NTFS volumes (see the NTFS section in File Systems). Compression and encryption cannot be combined. If you compress an encrypted file, the result is compressed but not encrypted (and vice versa). Use the following commands:

  • NTFS Compress (it is also on Top and Middle toolbars): compresses selected files and directories,
  • NTFS Uncompress (it is also on Top and Middle toolbars): uncompresses selected files and directories,
  • NTFS Encrypt: encrypts selected files and directories,
  • NTFS Decrypt: decrypts selected files and directories.

All of these commands are available on the Files/NTFS Commands menu. You can also compress and encrypt files and directories by setting or clearing the Compressed and Encrypted attributes with the Change Attributes command.
